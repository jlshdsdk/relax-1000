某文件系统采用位示图（1024 行，32 列）表示空闲盘块情况，位示图行和列、盘块号都从0开始编号，则4567 号块位于第（ ）行，（）列。
  1. A．22，142
  2. B．142，23
  3. C．23，143
  4. D．143，23
答案与解析

答案：B

类比行优先矩阵存储，行号=4567/32=142，列号=(4567%32)=23，故选B。

勘误：题干已按勘误为“4567号块”，已核对。

第 62 题
在现代操作系统中，文件分配表中引入了“簇”的概念，下列关于“簇”的说法中，错误的是 （）。
  1. A．磁盘容量不断增大，因此不再以盘块而以簇为基本单位进行盘块分配，一簇应包含扇区的数量与磁盘容量大小直接相关
  2. B．以簇为基本分配单位，可以减少FAT 表的表项数，在相同的磁盘容量下，FAT 表的表项数与簇的大小是成正比的
  3. C．以簇为基本分配单位，可以使FAT 表占用更少的存储空间
  4. D．以簇为基本分配单位，可以减少访问FAT 表的存取开销
答案与解析

答案：B

为了适应磁盘容量不断增大的需要，当进行盘块分配时，不再以盘块而以簇为基本单位，簇应包含的扇区数量与磁盘容量的大小直接相关。以簇为基本分配单位的优点如下：能适应磁盘容量不断增大的情况，减少FAT 表的表项数(在相同的磁盘容量下，FAT 表的表项数与簇的大小成反比)，使FAT表占用更少的存储空间，减少访问FAT 表的存取开销。

第 63 题
某文件系统采用位示图法管理外存储空间，每个磁盘块4KB，已知一块磁盘容量为40GB，则表示该磁盘所需的位示图需要占用的内存空间（）
  1. A．1280KB
  2. B．10240KB
  3. C．4096KB
  4. D．10MB
答案与解析

答案：A

位示图是利用二进制的一位来表示磁盘中的一个盘块的使用情况。一共需要40GB/4KB=10M 个磁盘块表示这些磁盘块需要10Mb/8b=1280KB。

  2. B．空闲链表法
  3. C．位示图法

第 65 题
若用8 个字（字长32 位）组成的位示图管理内存，字号、位号、块号均从0 开始算起，则块号为100 的内存块对应的位示图位置为（ ）。
  1. A．字号为3，位号为5
  2. B．字号为3、位号为4
  3. C．字号为4，位号为4
  4. D．字号为4，位号为5
答案与解析

答案：B

位示图中，0 ~ 31 在0 号字，32 ~ 63 在1 号字，64 ~ 95 在2 号字，96~127 在3号字，所以块号100 在3 号字中，3 号字的0 号位是96，1 号位是97，依此类推，块号100 在4 号位中。另解，块号为100 的内存块对应的位示图字号为100DIV32 = 3，位号为100MOD 32 = 4，即字号为3，位号为4。选择B选项。

第 67 题
关于空闲磁盘分配方式，说法错误的是（ ）
  1. A．位示图法空间开销固定，但可能需要线性复杂度找到空闲块
  2. B．空闲区表法空间开销可能很大，但方便找到一片连续的空闲块
  3. C．空闲链表法分配和回收非常简单，但不支持合并
  4. D．成组链表法克服了空闲区表法和空闲链表法表太长的缺点，且分配速度快且空间开销小
答案与解析

答案：C

C 错误，空闲链表法分为空闲盘块链和空闲盘区链，后者可以把连续的空闲盘块合并成一个区，支持合并，同时也减短了链表长度，通常采用首次适应算法，加快对连续盘块的分配，缺点是分配和回收略复杂。

第 68 题
在使用成组链表法方式下，若每个空闲盘块最多可以记录4 个空闲盘块号，内容是[3，11， 408，666]，3 表示已经记录3 个磁盘块，[11，408，666]分别是这三个空闲磁盘块的块号，它是一个栈， 666 所在方向是栈顶。现对某个进程回收2 个磁盘块，分别是[985，211]，超级块内容变为（ ），接着给另一个进程分配3 个空闲磁盘块，超级块的内容变为（ ）
  1. A．[5，11，408，666，985，211]，[2，11，408]
  2. B．[2，985，211]，[5，11，408，666]
  3. C．[1，11]，[2，11]
  4. D．[1，211]，[2，11，408]
答案与解析

答案：D

回收两个磁盘块，原本超级块记录了3 个空闲盘块号，但是现在还需要回收2个，超出了上限4，所以应该将985 入栈后，当前超级块的3 改成4，然后还需要回收211，此时超级块满了，那么把超级块的内容复制到盘块211，然后超级块改为[1，211]。接着分配3 个空闲磁盘块给进程，当前超级块只有一个211，所以把原来满了的块的内容重新复制到超级块，然后把211 分配给进程，然后当前超级块里面是[4, 11, 408, 666, 985]，依次把985, 666 分配给进程，至此已经分配了3 个空闲磁盘块，超级块的内容为[2, 11, 408]。此处推荐观看成组链接法视频，分配和回收都讲得很清晰：https://www.bilibili.com/video/ BV1HE41167kj?vd_source= 130baaebbac315d959b263869c0a7b39

第 69 题
下列关于文件系统和虚拟文件系统（VFS）的说法中正确的是（ ）。
  1. A．每种操作系统都有自己专有的文件系统，不同操作系统之间文件系统完不兼容
  2. B．VFS 不能同时支持多种文件系统
  3. C．通过VFS，应用程序可以不关心底层使用的是哪种文件系统
  4. D．文件系统挂载是一个不可逆的操作，一旦挂载无法卸载
答案与解析

答案：C

虚拟文件系统(VFS)为应用程序提供了一个统一的接口来访问不同的底层文件系统，使得应用程序不需要关心底层文件系统的具体类型。故案为选项C。

第 70 题
关于虚拟文件系统（VFS），以下描述中不正确的是（ ）
  1. A．VFS 为不同的文件系统提供一个抽象层
  2. B．VFS 允许用户在不同类型的文件系统中进行无缝切换
  3. C．所有操作系统都使用相同的VFS 实现
  4. D．VFS 允许系统调用如open 和read 与特定文件系统无关
答案与解析

答案：C

虽然许多操作系统都实现了虚拟文件系统(VFS)这一概念，但它们的实现是不同的。VFS 的具体实现会因操作系统而异。故答案为选项C。

第 71 题
虚拟文件系统VFS 中的对象类型不包括（ ）。
  1. A．超级块（superblock）对象
  2. B．索引节点（inode）对象
  3. C．数据（data）对象
  4. D．文件（fle）对象

为实现虚拟文件系统，UNIX抽象了四种对象类型：超级块对象、索引节点对象、目录项对象、文件对象，其中不包括数据对象，选择C 选项。

第 72 题
在计算机操作系统中，对于文件挂载的过程和相关概念，哪个选项的描述是正确的?（ ）
  1. A．文件挂载是将一个文件复制到另一个目录中，并将其与目录树中的挂载点关联，使其可访问和操作
  2. B．文件挂载是将一个目录连接到另一个目录，使其成为目录树的一部分，并与外部文件系统关联
  3. C．文件挂载是将一个文件系统连接到计算机的硬件设备，使文件系统中的文件和目录可供访问
  4. D．文件挂载是将一个文件压缩并加密后存储在磁盘上，并与特定的解密工具关联，以便访问和操作
答案与解析

答案：B

选项B 描述了文件挂载的正确概念，即将一个目录连接到另一个目录，使其成为目录树的一部分，并与外部文件系统关联，以便访问和操作其中的文件和目录。通过挂载，外部文件系统中的文件和目录可以在目录树中访问和操作。
