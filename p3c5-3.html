第 61 题
下列关于固态硬盘SSD 的说法中，正确的有（ ）。
I. 固态磁盘是基于闪存技术的存储技术
II. 固态磁盘在写入前必须进行擦除
III. 固态磁盘的读写性能、使用寿命均优于机械硬盘
IV. 固态硬盘写入时，总是要选择擦写次数少的存储块
  1. A．I、II
  2. B．I、II、III
  3. C．I、II、IV
  4. D．II、III、IV
答案与解析

答案：A

Ⅰ正确，固态硬盘基于闪存技术。 Ⅱ正确，固态硬盘以页为读写单位，只有在一页所属的块整个被擦除后，才能对这一页进行写入。 Ⅲ错误，固态磁盘的读写性能优于机械硬盘，但是固态硬盘的NAND闪存中的块有擦写次数限制，其使用寿命一般短于机械硬盘。 Ⅳ错误，Ⅳ描述的是动态磨损均衡，而在静态磨损均衡中，会对数据块进行检测，尽可能保证各块写入和擦除均衡，并非是每次写入都选择长期存放数据而很少擦写的块。

第 62 题
下列关于固态硬盘（SSD）的叙述中，不正确的是（ ）。
  1. A．固态硬盘的读写是以页为单位的
  2. B．固态硬盘的擦除是以页为单位的
  3. C．固态硬盘的写入速度比读取速度慢很多
  4. D．固态硬盘的写入次数有限，引入磨损均衡可以延长使用寿命
答案与解析

答案：B

读写以页为单位，擦除以块为单位。随机写的速度比读慢，原因如下：只能写入被擦除的块，擦除块比访问块慢得多。 • • 修改一个页中的部分数据，需要拷贝这个块中其他页到被擦除的块进行修改磨损均衡 • 动态磨损均衡：自动选磨损少的块写入，早期常使用动态方式，这种方式会导致冷数据块一直得不到擦除，各个块擦除并不均衡。冷数据：只读数据或者系统数据，修改很少的数据块静态磨损均衡：将冷数据块转移到擦除较多次的块（老块），现代多使用静态+动态磨损均衡结合的方式，增加了闪存的寿命。注意：闪存的存储介质是ROM，但是SSD里有闪存翻译层，其中地址映射表是由速度较快的DRAM 实现，所以SSD 可以说存储介质是ROM，但是不可以说只有ROM，内部还是有DRAM的存在。

第 63 题
进程P 通过执行系统调用从网络中读取成块数据，系统采用硬件中断驱动I/O 方式。已知在I/O 全过程中包含如下操作：①将数据从网卡（网络控制器）的数据寄存器读入内核缓冲区②将进程P插入就绪队列③将进程P 插入阻塞队列并进行进程调度④网卡接口准备好数据，向CPU 发出硬件中断请求。若进程P 发起I/O 请求时由于网络数据未到达而立即放弃CPU ，那么在网络数据块到达后，上述操作的正确执行顺序是（）。
  1. A． ③→④→①→②
  2. B． ④→①→②
  3. C． ④→②→①
  4. D． ③→④→②→①
答案与解析

答案：B

读题目问的是“在网络数据块到达后”的执行顺序。在发起I/O 请求初期，由于数据未就绪，进程P 就已经完成了操作③（进入阻塞队列，让出处理机）。当网络数据块真正到达网卡时，网卡硬件首先发出中断请求，即操作④。 CPU 响应中断，暂停当前运行的随机进程Q，转去执行网卡的中断服务程序。在中断服务程序中，CPU 通过执行I/O 指令，将数据从网卡控制器的数据寄存器读入内核系统缓冲区中，即操作①。随后，由于数据已经进入系统缓冲区，中断服务程序调用相关内核函数，将因等待该网络输入而阻塞的进程P 的状态修改为就绪态，并移入就绪队列，即操作
②。因此，在这个时间节点之后的正确操作链条为：④→①→②。

第 64 题
键盘属于典型的中断驱动型低速字符设备。当用户在键盘上输入一个字符，触发键盘硬件产生中断请求，操作系统内核调度键盘中断服务例程执行完毕时，所输入的字符数据此时存放在（）。
  1. A． CPU 中的通用寄存器（如AL），以便调度程序直接传递给用户程序
  2. B． 设备控制器的数据缓冲寄存器中，等待用户进程执行in 指令（IO 指令）
  3. C． 操作系统的内核缓冲区中，随后系统会据此解除用户进程的阻塞状态

答案：C

第 65 题
某进程P 执行系统调用请求向打印机输出一串较长的字符串，系统采用中断控制方式。下列关于该输出过程的叙述中，正确的是（）。
  1. A． 该字符串的所有字符，都是在系统调用服务例程（如sys_write）的控制下依次串行写入打印机端口的
  2. B． 第一个字符在系统调用服务例程控制下输出并启动外设，后续字符的输出均由字符打印中断服务程序控制完成
  3. C． 当打印机正在打印某个字符（外设工作段）时，进程P 在主存中保持运行状态并持续读取状态端口
  4. D． 在执行字符打印中断服务程序搬运后续字符时，CPU 运行在进程P 的环境及地址空间内
答案与解析

答案：B

完整过程：字符串的第一个字符是在系统调用服务例程（sys_write）的控制下输出到数据端口并发送启动打印命令的；之后进程P 便执行scheduler()主动阻塞自己让出处理机；剩下的所有字符打印，都是在其他进程（如Q）运行期间，由打印机硬件完成上一个字符后触发的硬件中断服务程序来控制输出的。 A错误：若所有字符都在sys_write系统调用服务例程中依次串行输出，则整个I/O过程CPU都需要持续等待并轮询设备状态，这是程序直接控制（轮询）方式。中断控制方式的特点就是CPU启动设备后即转向其他工作，待设备完成时通过中断信号通知CPU进行后续处理。 C错误：打印机打印字符的速度远低于CPU执行速度。在中断控制方式下，进程P发出系统调用并启动设备后会立即进入阻塞态，让出CPU给其他进程，绝不会保持运行状态并循环查询状态端口。 D 项错误，执行中断服务程序时系统正处于被打断的进程Q 的环境和地址空间中，需要通过公共映射的内核缓冲区作为中介来传递数据。

第 66 题
中断I/O 方式和DMA 方式是现代计算机中管理外设的两大核心技术。关于这两种方式在硬件请求与响应机制上的对比，下列说法中错误的是（）。
  1. A． 中断控制方式向CPU 请求的是处理机时间，而DMA 方式向CPU 请求的是系统总线控制权
  2. B． CPU 响应中断请求的时机在一条指令周期结束时，而响应DMA 总线请求的时机在任何一个总线事务完成时
  3. C． 中断方式下的实际数据传送过程完全通过软件完成，而DMA 方式下的数据传送由硬件直接控制完成
  4. D． 周期挪用DMA 在挪用存储周期进行字传送时，由于同样涉及进程调度，其保护和恢复现场的系统开销与中断一致
答案与解析

答案：D

DMA方式（周期挪用）的核心优势之一就是开销极低。周期挪用的过程：当DMA控制器请求“周期挪用”时，CPU仅仅需要暂停一个存储（总线）周期的操作，让出一个内存读写周期供DMA传送一个字。此时CPU并没有发生“进程调度”，无需进行保护和恢复现场（即程序状态字、通用寄存器等的压栈出栈操作）。对比中断：响应中断时，必须进行完整的上下文切换（保护和恢复现场），开销远大于一个存储周期。因此，D项称周期挪用DMA的保护恢复现场开销“与中断一致”是完全错误的。

第 67 题
用户进程请求打印文件，操作系统调用打印机驱动程序。若此时打印机正忙，驱动程序将该进程阻塞。关于此过程，下列叙述错误的是（）。
  1. A． 进程在阻塞前，CPU 处于内核态
  2. B． 驱动程序执行过程中，可能会调用操作系统的进程调度程序
  3. C． 进程被阻塞后，CPU 将立即执行该驱动程序的中断服务例程
  4. D． 驱动程序是操作系统内核的一部分，与硬件控制器紧密相关

C 错：进程因设备忙被阻塞后，CPU 会调用调度程序切换到其他就绪进程执行。中断服务例程只有在硬件设备完成当前任务（如打印完一页）发出中断信号时才会被CPU 执行，而不是在进程刚被阻塞时立即执行。A、B、D 均正确描述了驱动程序在内核态运行、可能引发调度以及与硬件强绑定的特性。

第 68 题
现代多任务操作系统中关于内核低级例程在控制硬件时的分工协作，下列表述正确的是（ ）。
  1. A． 只有设备驱动程序能够对硬件进行直接控制，中断服务程序绝不与硬件控制器交互
  2. B． 驱动程序负责向控制器的寄存器写入值来发起操作，而中断服务程序在硬件完成任务后负责读取状态、发送确认信号
  3. C． 中断处理层由于和硬件紧密相关应尽量加以屏蔽，因此在层次组织中它位于设备驱动程序的上层
  4. D． 只要没有涉及到具体的硬件细节，对各种设备都需要进行的公有管理工作都是在中断服务程序层完成的
答案与解析

答案：B

第 70 题
设备独立性软件（与设备无关的I/O 软件）位于用户层I/O 软件和设备驱动程序之间。下列任务中，不属于设备独立性软件职责范围的是（）。

第 71 题
在现代操作系统中，用户进程通过系统调用（如read）读取块设备中的数据时，内核通常会在内核空间开辟系统缓冲区，数据先从设备进入系统缓冲区，再复制到用户空间的工作区。操作系统不直接将外设数据读入用户工作区的原因包括（）。
Ⅰ. 块设备与用户缓冲区之间的基本传输单位和内存对齐要求可能不匹配
Ⅱ. 用户空间的页面在慢速I/O 期间可能被换出或在物理内存中发生动态移动
Ⅲ. 引入系统缓冲区便于内核实现页高速缓存与预读机制，提高数据复用率
Ⅳ. 用户进程在慢速I/O 期间会进入阻塞态，操作系统会阻塞或挂起该进程并进行页表切换
  1. A． Ⅰ、Ⅱ、Ⅲ
  2. B． Ⅰ、Ⅲ、Ⅳ
  3. C． Ⅰ、Ⅱ、Ⅳ
  4. D． Ⅰ、Ⅱ、Ⅲ、Ⅳ
答案与解析

答案：A

Ⅰ正确：块设备（如磁盘、SSD）的硬件传输是以“块”或“扇区”为单位的，且通常要求内存起始地址严格对齐。而用户进程定义的缓冲区大小和起始地址是由程序员任意决定的。内核缓冲区在其中起到了“数据对齐和重组”的桥梁作用。 Ⅱ正确：块设备数据读入内存通常通过DMA（直接内存访问）控制器。DMA传输期间需要目标物理内存地址绝对固定。用户空间的页面由于受到虚拟内存管理（如页面置换算法、内存紧凑）的控制，在耗时较长的磁盘I/O期间，随时可能被换出到外存，或被移动物理位置。如果直接将外设数据读入用户工作区，会导致DMA往错误的物理地址写入数据。而内核系统缓冲区通常是“锁定 （Pinned）”在物理内存中的，绝不会移动或换出，确保了DMA的安全。 Ⅲ正确：如果直接读入某一个进程的用户空间，该数据就无法被系统内的其他进程共享。引入内核缓冲区（PageCache）后，系统可以保留这份数据，当其他进程也读相同文件时直接从内核复制即可。同时，内核还能借此实现“预读”，在用户还没请求时就提前把后续块读入系统缓冲区，极大地提高了I/O效率。 Ⅳ错误（属于强干扰项，叙述本身正确，但非原因）：在传统的同步read系统调用中，由于磁盘I/O属于慢速操作，用户进程确实会被剥夺CPU并进入阻塞态。为了让其他进程运行，操作系统必然会进行进程调度，从而切换页表（更新页表基址寄存器）。但是，这并不是操作系统“不直接将外设数据读入用户工作区”的原因。无论是否使用内核缓冲区，进程执行阻塞I/O 时都会因等待设备而被阻塞，并随之发生上下文切换（包括页表切换）。这属于I/O 操作的正常调度行为，与“为什么不直接读入用户工作区”并无因果关系，因此不是原因。

第 72 题
缓冲与缓存是设备独立性软件管理内存临时存储区的两种重要技术。下列关于二者区别与联系的叙述中，错误的是（）。
  1. A． 缓冲的核心目的是缓和速度或数据粒度不匹配；缓存的核心目的是加速对数据的重复访问
  2. B． 缓冲区中的数据通常是单向流动的“中转站”，被消费后即失效；缓存中的数据是源数据的副本，可被反复读取
  3. C． 缓冲区管理通常更关注系统吞吐量；磁盘高速缓存管理更关注缓存命中率
  4. D． 缓冲区保存的数据一定是物理源数据的子集；缓存区的数据在发往目的地后源处可以不再保留
答案与解析

答案：D

A、B、C 项完全符合缓冲与缓存特性的标准对比。D 项颠倒了二者的关系：缓冲区是一个“中转站”，其中的数据可能是唯一的，数据源将数据发往缓冲区后就可以不再保留；而缓存 （Cache）保存的数据一定是对应数据源（如磁盘块）中数据的子集，属于高速副本。

第 73 题
现代操作系统在内存中开辟磁盘高速缓存（Disk Cache）来充分利用局部性原理。关于磁盘高速缓存的读写策略，下列叙述错误的是（）。
  1. A． 磁盘高速缓存逻辑上属于磁盘，物理上则是驻留在内存中的RAM 区
  2. B． 采用写通（Write-through）策略时，系统调用在数据同步写入物理磁盘后才返回，性能提升极其有限
  3. C． 采用回写（Write-back）策略时，脏块在刷回磁盘前若系统断电，会导致数据永久丢失
  4. D． 回写策略虽然牺牲了即时可靠性，但其根本目的是为了利用磁盘调度算法减少平均寻道时间
答案与解析

答案：D

设置磁盘缓冲区或高速缓存的最主要、最根本目的是减少物理磁盘的I/O 总次数，缓和高速CPU/内存与慢速磁盘之间的巨大速度差异。回写策略（延迟写入）可以通过“合并写入”和“批量写入”大幅削减实际I/O 次数。虽然积累多个I/O 请求后可以让磁盘调度算法优化寻道时间，但这只是一个派生、次要的好处，而不是其首要设计目的。

第 74 题
关于SPOOLing 系统中的“输出进程”（即负责将数据从输出井传送到打印机的进程），下列叙述中正确的是（）。
  1. A． 该进程由提交打印请求的用户作业所创建
  2. B． 只有当输出井中存在待打印作业时，该进程才会被创建
  3. C． 该进程直接从用户作业的地址空间读取待打印数据
  4. D． 该进程由操作系统管理，负责执行对物理打印机的实际I/O 操作
答案与解析

答案：D

A 错误：“输出进程”是一个系统级的后台服务进程（或守护进程），它独立于任何用户作业，由操作系统在启动时创建和管理。B 错误：该进程通常是常驻内存的，而不是按需创建。当井中没有任务时，它处于休眠或阻塞状态；当井中有新任务时，操作系统会唤醒它。C 错误：用户作业的数据已经被转存到磁盘的“输出井”中。输出进程的数据来源是“输出井”，而不是任何用户作业的地址空间。D 正确：这准确描述了“输出进程”的职责。它是一个系统进程，拥有执行底层I/O 操作的权限，是SPOOLing 系统中唯一直接与物理打印机硬件打交道的模块。
