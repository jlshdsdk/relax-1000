第 31 题
已知某DDR2 SDRAM 内存条的数据总线位宽为64 位（8B），在每个存储器总线时钟的上升沿和下降沿各传一次，其标称的最大理论数据带宽为6.4 GB/s，则下列关于该内存条参数的推断中，错误的是（）。
  1. A． 该内存条存储器总线上的等效数据传输率（传送次数）为800M 次/秒
  2. B． 芯片内部存储阵列的实际工作频率（核心频率）为400MHz
  3. C． 存储器总线的实际时钟频率为400MHz
  4. D． 该芯片内部I/O 缓冲采用了4 位（4n）数据预取技术，那么内部存储阵列一次预取的量是32B。
答案与解析

答案：B

A正确：根据公式带宽=等效传输率×数据位宽，可反推出等效传输率= 6.4GB/s/8B = 6400MB/s/8B = 800M 次/秒。 B 错误：等效传输率=核心频率×预取倍数，可反推出核心频率= 800M / 4 = 200MHz。 C 正确：由于双沿传输特性，总线时钟频率=等效传输率/ 2，即800M / 2 = 400MHz。 D 正确：预取技术是指存储器核心一次从存储阵列中取出多位数据，先放入内部缓冲区，然后再以更高的外部接口速率分多次送到数据总线上。这样可以在不显著提高存储阵列核心频率的情况下，提高外部数据传输率。DDR2 SDRAM芯片内部标准采用的是4位(4n)预取技术，所以存储阵列一次预取的量是32B，每次在数据总线传输8B 数据，这样就可以实现高速传输。

第 32 题
假定DDR3 SDRAM 芯片内部核心频率为133.25MHz，在每个存储器总线时钟的上升沿和下降沿各传一次，采用8 位预取技术，与之相连的存储器总线每次传输8B，则下面有关叙述中，错误的是 （）。
  1. A．芯片内部I/O 缓冲64B
  2. B．存储器总线每秒传1066M 次数据
  3. C．存储器总线的时钟频率为1066MHz
  4. D．存储器总线的带宽大约为8.5GB/s
答案与解析

答案：C

A 正确，DDR3 SDRAM芯片内部I/O 缓冲采用8 位预取技术，即内部存储阵列一次取出够总线传输8 次的数据量放在I/O 缓冲，I/O 缓冲大小为8×8B=64B。B 正确，芯片内部核心频率是指每秒内存储阵列往I/O 缓存放数据的频率，所以存储总线实际传输数据的频率为核心频率× 预取位数n ，故存储器总线每秒传送数据的次数为133.25M×8=1066M，其带宽为1066M× 8B≈8.5GB/S，D也正确。因为存储器总线每个时钟周期传送两次数据，所以存储器总线时钟频率为1066M/2=533MHz。综上所述，答案为选项C。

第 34 题
某计算机使用4 体低位交叉编址存储器，存取周期T = 80ns，总线启动访问间隔Δt = 20ns。在存储器总线上出现的主存地址（十进制）序列为8005，8006，8007，8008，8001，8002，8003，8004， 8000，则总存取时间是（ ）。（到最后一次存取的存取周期结束为止）
  1. A．240ns
  2. B．280ns
  3. C．300ns
  4. D．720ns
答案与解析

答案：C

根据访问地址求出访问存储体体号序列（地址% 4）：1，2，3，0，1，2，3， 0，0。可发现只有最后访问8004和8000时发生了体冲突，即：体1：0ns→80ns（首次启动）体2：20ns→100ns（间隔Δt）体3：40ns→120ns（间隔Δt）体0：60ns→140ns（间隔Δt）体1：80ns→160ns（距首次启动80ns，满足T）体2：100ns→180ns（距首次启动80ns）体3：120ns→200ns（距首次启动80ns）体0：140ns→220ns（距首次启动80ns）体0：220ns→300ns（距上一次体0启动140ns→220ns，间隔80ns）最后一个访问（第9个地址，体0）的完成时间为300 ns，C正确。

第 36 题
某计算机主存采用4 体低位交叉编址结构，且总线和存储器支持突发传送。设总线传输周期为r ，每个存储模块的存取周期T=4r。在程序执行过程中，CPU 依次发出六个主存地址（十进制）的访存请求序列为：8, 17, 21, 12, 31, 28。忽略其他开销，假设第一个请求在第1 个总线周期发出，则该序列中会发生体冲突的访存地址有（）。
  1. A． 21 、12
  2. B． 21 、28
  3. C． 12 、28
  4. D． 21、12 、28
答案与解析

答案：B

第一步，先对所有地址取模（地址mod 4），地址序列[8,17, 21, 12, 31, 28]对应的体号序列为：[0, 1, 1, 0, 3, 0]。 【陷阱预警（静态窗口法易错点）】如果只用眼睛扫，看哪些相同体号的间隔小于4： 21(体号1)和17(体号1)挨着，间隔为1 ->21冲突。 12(体号0)和8(体号0)间隔为3 ->12冲突。 28(体号0)和12(体号0)间隔为2 ->28冲突。按照这个错误逻辑会错选D。记住，前一次冲突引发的流水线停顿，会改变后续所有指令的发射时间。（这个跟14年计组大题44题（4）中为什么指令1 的执行不会因为与指令5 的数据相关而发生阻塞这一问有异曲同工之妙）为了绝对严谨，我们按照总线周期（设为r）一步步往后推。一个模块一旦启动，将占据4个周期（例如第1周期启动，第1、2、3、4周期忙碌，第5周期恢复空闲）。因此在这六次访存中，只有地址21和地址28在试图发出时遭遇了模块忙碌，从而发生了体冲突。

第 37 题
假定采用多模块交叉存储器组织方式，存储器芯片和总线支持突发传送，CPU 通过存储器总线读取数据的过程为：发送首地址和读命令需1 个时钟周期，存储器准备第一个数据需8 个时钟周期，随后每个时钟周期总线上传送1 个数据，可连续传送8 个数据。若主存和cache 之间交换的主存块大小为64B，存储宽度和总线宽度都为8B，则cache 的一次缺失损失（缺失开销）至少为（ ）个时钟周期。
  1. A．33
  2. B．20
  3. C．17
  4. D．65
答案与解析

答案：C

一次缺失需要从主存读取一个主存块（64B)，每个突发传送总线事务可以读取8B*8，因此需要一个突发传送总线事务。每个突发传送总线事务所用时间为1+8+8=17 个时钟周期。

第 39 题
关于多模块存储器，以下叙述正确的是（ ）。
  1. A． 低位交叉编址在稳定流水线状态下，带宽随模块数m 的增加可以无限提升，模块越多越好
  2. B． 突发传送是多模块交叉存储器的专属功能，单颗DRAM 芯片自身不支持突发传送
  3. C． 高位交叉编址中，由于程序的空间局部性，CPU 连续访问的地址往往集中在同一模块，导致该模块成为热点，其余模块大量空闲，无法体现多体并行的优势
  4. D． 低位交叉编址通过缩短每个存储模块的存取周期来提高存储器带宽
答案与解析

答案：C

A错：稳定流水线带宽上限=字长/r（总线传输周期），一旦m ≥T/r，继续增加m带宽不再提升，反而增加硬件成本和设计复杂度。 B错：单颗SDRAM芯片本身就支持突发传送，原因是芯片内部有行缓冲区——激活一行后，同一行内的数据可以在每个时钟周期连续读出，无需重复发送地址。突发传送与交叉编址无必然关系。 C正确：高位交叉编址（连续编址）中，相邻地址位于同一个模块，程序空间局部性恰好导致频繁访问集中于少数模块，其他模块闲置，完全失去多体并行优势。这是高位交叉仅适合容量扩展、不适合性能提升的根本原因。 D错：低位交叉编址不改变单个模块的存取时间T，而是利用多体流水线并行工作（空间并行技术）来提高整体吞吐率。

下列关于固态硬盘SSD 的说法中，正确的是（ ）。
  1. A．固态硬盘属于磁表面存储器
  2. B．固态硬盘的闪存翻译层相当于磁盘中的磁盘控制器，起到地址转换的作用
  3. C．固态硬盘的随机读时延远低于常规硬盘，但随机写时延和常规硬盘的相差不大
  4. D．在对固态硬盘的某块写入信息时，不必按照块内页的顺序写入信息

第 42 题
下列关于固态硬盘（SSD）的说法中，错误的是（ ）。
  1. A．固态硬盘抗震性强、受机械震动影响较小，更适合移动设备使用。
  2. B．固态硬盘的磨损均衡技术中，动态磨损均衡比静态磨损均衡技术更先进、表现更优秀。
  3. C．固态硬盘的数据存储于Flash 芯片之中。
  4. D．机械硬盘使用的硬盘调度算法不一定适用于固态硬盘。
答案与解析

答案：B

静态磨损均衡技术比动态更先进、更优秀； SSD损均衡技术大致分为两种： • 动态磨损均衡。写入数据时，优先选择擦除次数少的新闪存块。老的闪存块先歇一歇。静态磨损均衡。这种技术更为先进，就算没有数据写入，SSD也会监测并自动进行数据分配， • 让老的闪存块承担以读为主的存储任务。同时让较新的闪存块腾出空间，以承担更多以写为主的存储任务。如此一来，各闪存块的寿命损耗就都差不多。

第 43 题
下列关于固态硬盘SSD 的说法中，正确的有（ ）。
I. 固态硬盘是基于闪存技术的存储技术
II. 固态硬盘在写入前空闲页必须是已擦除状态
III. 固态硬盘的读写性能、使用寿命均优于机械硬盘
IV. 固态硬盘写入时，总是要选择擦写次数少的存储块
  1. A．I、II
  2. B．I、II、III
  3. C．I、II、IV
  4. D．II、III、IV
答案与解析

答案：A

Ⅰ正确，固态硬盘基于闪存技术。 Ⅱ正确，固态硬盘以页为读写单位，只有在一页所属的块整个被擦除后，才能对这一页进行写入。 Ⅲ错误，固态硬盘的读写性能优于机械硬盘，但是固态硬盘的NAND闪存中的块有擦写次数限制，其使用寿命一般短于机械硬盘。 Ⅳ错误，Ⅳ描述的是动态磨损均衡，而在静态磨损均衡中，会对数据块进行检测，尽可能保证各块写入和擦除均衡，并非是每次写入都选择长期存放数据而很少擦写的块。

第 44 题
下列关于固态硬盘(SSD)的叙述中，不正确的是（ ）。
  1. A．固态硬盘的读写是以页为单位的
  2. B．固态硬盘的擦除是以页为单位的
  3. C．固态硬盘的写入速度比读取速度慢很多
  4. D．固态硬盘的写入次数有限，引入磨损均衡可以延长使用寿命
答案与解析

答案：B

读写以页为单位，擦除以块为单位。随机写的速度比读慢，原因如下：
①只能写入被擦除的块，擦除块比访问块慢得多。
②修改一个页中的部分数据，需要拷贝这个块中其他页到被擦除的块进行修改
③磨损均衡动态磨损均衡：自动选磨损少的块写入，早期常使用动态方式，这种方式会导致冷数据块一直得不到擦除，各个块擦除并不均衡。冷数据：只读数据或者系统数据，修改很少的数据块静态磨损均衡：将冷数据块转移到擦除较多次的块（老块），现代多使用静态+动态磨损均衡结合的方式，增加了闪存的寿命。注意：固态硬盘的核心存储介质是NAND 闪存（NAND Flash），属于非易失性存储器。此外，现代SSD内部通常还会集成一块速度较快的DRAM（动态随机存取存储器），用作缓存（Cache），主要用来存放闪存翻译层的地址映射表以及缓存读写数据，以此来极大提升SSD的工作效率。

第 45 题
给定两个长度为N 的一维数组a 和b（N 极大，远远超过Cache 容量），针对以下两种代码写法，哪种写法对Cache 的利用率更高（局部性更好）？下列关于cache 的描述中，正确的是（ ）。
  1. A． 写法1 更好，它把不同的操作分开了，指令的时间局部性更好
  2. B． 写法1 更好，它对数组a 的访问具有更好的空间局部性
  3. C． 写法2 更好，它显著提升了数组a 的时间局部性
  4. D． 写法2 更好，它显著提升了数组b 的空间局部性

答案：C

Ⅱ. 部件①为比较器，直接映射Cache 中该部件仅1 个，且其比较的位宽应为32 位
Ⅲ. 部件②为与门，如果比较器比较结果为相同，并且该Cache 行的有效位为1，则该与门输出为1，表示Cache 命中
Ⅳ. 部件③为多路选择器（MUX），其控制信号来自于块内地址的低2bit
Ⅴ. 假设写操作采用直写方式（Write-Through），则该Cache 的总容量位数至少是593920 位
Ⅵ.直接映射无需考虑替换算法，发生冲突直接替换冲突数据块即可
  1. A． Ⅰ、Ⅲ、Ⅴ、Ⅵ
  2. B． Ⅰ、Ⅱ、Ⅲ
  3. C． Ⅱ、Ⅳ、Ⅴ、Ⅵ
  4. D． Ⅰ、Ⅲ、Ⅳ、Ⅵ
答案与解析

答案：A

Ⅰ.正确16B ，按字节编址，因此块内地址（Offset ）占主存块大小为log2 (16) = 4位。Cache数据区容量为64KB，共有64KB/16B = 4096行，因此Cache行号（Index）占log2 (4096) = 12 位。主存地址共32位，因此标记位（Tag）长度为32 - 12 - 4 = 16位。 Ⅱ错误：部件①确实是比较器，在直接映射中由于每个主存块只能映射到唯一的Cache行，每次只需比较1个Tag，因此该部件仅有1个。陷阱在于比较的位宽：比较器只需要对比主存地址中的Tag字段与Cache标记阵列中存储的Tag，因此它的位宽应与Tag长度一致，即16位，而不是32位。 Ⅲ正确：部件②是与门。Cache命中的严格物理条件是：Tag匹配成功且该行的有效位（ValidBit）为1。两者同时满足，与门输出高电平（1），产生Hit信号。 Ⅳ错误：部件③是一个4路选择器，其作用是从命中的16B Cache行（包含4个32位的字）中，选出CPU需要的那1个字（4B）。从4个字中选择1个，需要2位控制信号。这2位信号来自块内地址（4位，设为[3:0]）。其中，低2bit [1:0]用于字内字节选择，而高2bit [3:2]才用于字选择（Word Offset）。因此控制信号应来自块内地址的高2bit。

内存地址空间为64M=2^26，物理地址为26 位。按字节编址，主存块长64B，块内地址为6bit。cache 数据容量8 * 64B=512B，标记阵列容量为532-512=20B，一共8 行，每行的标记信息一共20bit，回写方式需要1bit 脏位，另外1bit 有效位，因此tag 位为20-1-1=18bit。因此可以知道组号位数为26-18-6=2bit，可知该cache 采用8/2^2=2 路组相联。比较器数量为2.答案选C。关于cache 比较器个数记忆：k 路组相联就有k 个比较器。假设一个cache 有n 行 • 直接映射可看作n 组1 路组相联，1 个比较器 • k 路组相联映射为n/k 组k 路组相联，k 个比较器全相联可看作1 组n 路组相联，n 个比较器 •

第 59 题
在指令存储器设置一个容量为1KB 的cache，采用4 路组相联，每块2 个字（字长16bit），按字节编址。其cache 中选出命中的行（如果存在）需要几个多路选择器以及每个多路选择器需要几位来控制（）。
  1. A．1 个多路选择器，每个多路选择器需要4bit 用于控制
  2. B．4 个多路选择器，每个多路选择器需要2bit 用于控制
  3. C．1 个多路选择器，每个多路选择器需要2bit 用于控制
  4. D．4 个多路选择器，每个多路选择器需要4bit 用于控制
答案与解析

答案：C

由于cache采用4路组相联，所以cache中有4个比较器，比较后通过一个多路选择器选择出一个块，每组有四个块，所以用2bit控制多路选择。实现一个四路组相联的cache需要四个比较器和一个4选1的多路选择器来判断被选中的组中哪一个单元与标记匹配。

第 60 题
某32 位计算机的cache 容量为16KB，按字节编址，cache 行的大小为16B，若主存与cache 地址映像采用直接映像方式，则主存地址为0x1234E8F8 的单元装入cache 的地址是（ ）。
  1. A．00010001001101
  2. B．11010011101000
  3. C．01000100011010
  4. D．10100011111000
答案与解析

答案：D

cache 地址总共为14 位，最后4 位是块内偏移量，所以和主存地址的最后4 位一样。由于采用直接映射，主存地址的最后14 位，就是对应在cache 的地址。
