第 1 题
在操作系统中，I/O 设备是计算机系统与外部世界交互的桥梁。下列关于I/O 设备及其管理方式的叙述中，错误的是（）
  1. A．从数据传输单位来看，键盘和鼠标属于字符设备，而磁盘和磁带属于块设备。
  2. B．为了方便用户使用和提高系统可移植性，应用程序通常通过物理设备名直接访问I/O 设备。
  3. C．设备控制器是CPU 与I/O 设备之间的接口，负责接收CPU 的命令并控制I/O 设备完成具体操作。
  4. D．按共享属性划分，打印机通常被视为独占设备，而磁盘则通常被视为可共享设备。
答案与解析

答案：B

A 正确，字符设备是以字符为单位进行数据传输的设备，如键盘、鼠标、打印机等。块设备则是以数据块为单位进行数据传输的设备，如磁盘、磁带、光盘等。 B 错误，为了实现设备无关性（或称设备独立性），方便用户使用和提高系统的可移植性与可适应性，应用程序通常通过逻辑设备名来请求使用I/O 设备，而不是直接使用物理设备名。操作系统负责将逻辑设备名映射到具体的物理设备名。如果应用程序直接使用物理设备名，那么当物理设备更换或配置改变时，应用程序就需要修改，这不利于移植和维护。 C 正确，设备控制器是介于CPU 和I/O 设备之间的硬件部件。它负责接收来自CPU 的指令和数据，并将其转换为I/O 设备能够理解的控制信号和操作序列，然后控制I/O 设备执行具体任务。同时，它也会将设备的状态和I/O 操作的结果反馈给CPU。 D 正确，独占设备在一段时间内只能被一个进程所使用，如打印机。可共享设备允许多个进程同时 （宏观上）访问，如磁盘。操作系统会通过调度和管理机制来协调多个进程对共享设备的访问。

第 2 题
下列关于I/O 端口编址方式和访问I/O 端口的叙述中，错误的是（ ）
  1. A．在独立编址方式下，I/O 端口拥有独立的地址空间，访问这些端口需要使用专门的I/O 指令。
  2. B．在统一编址方式下，I/O 端口和内存单元统一编址，访问I/O 端口就像访问内存单元一样，可以使用通用的访存指令。
  3. C．采用统一编址方式时，用户程序可以直接通过普通的访存指令自由读写任何映射到内存地址空间的I/O 端口，无需操作系统干预。
  4. D．设备控制器中的数据寄存器、状态寄存器和控制寄存器都通过各自的I/O 端口地址与CPU 进行信息交互。
答案与解析

答案：C

C 错误，即使采用统一编址（内存映射I/O），映射到I/O 设备寄存器的内存地址通常也受到内存保护机制的控制。用户程序在用户态下试图直接访问这些受保护的地址（即I/O 端口）仍然会引发保护异常或需要通过系统调用请求操作系统内核来执行实际的I/O 操作。允许用户程序“自由读写任何...I/O 端口，无需操作系统干预”会破坏系统的安全性和稳定性。

第 3 题
下列各项中，属于I/O 接口功能的是（ ）
Ⅰ．数据缓冲与格式转换
Ⅱ．错误与状态检测
Ⅲ．I/O 操作的控制与定时
  1. A．Ⅰ
  2. B．Ⅰ、Ⅲ
  3. C．Ⅰ、Ⅱ
  4. D．Ⅰ、Ⅱ、Ⅲ
答案与解析

答案：D

I/O 接口的功能为：①地址译码，选取接口寄存器；②接收控制命令，提供工作状态信息并进行状态检测；③数据缓冲与格式转换以及数据的检错、纠错；④I/O 控制与定时，如中断、DMA控制逻辑设备操作等；⑤对内与主机通信，对外与外设通信。综上Ⅰ、Ⅱ、Ⅲ均属于I/O 接口的功能，故本题选D。

第 4 题
下列关于I/O 端口和接口的说法中，正确的是（ ）。
  1. A．采用独立编址方式时，通过地址线来区别存储单元和I/O 设备
  2. B．采用独立编址方式时，需要设置专门的I/O 指令访问端口
  3. C．按照数据传送格式，接口可以分为同步传送接口和异步传送接口
  4. D．采用统一编址方式时，通过指令格式来区别存储单元和I/O 设备

答案：B

采用独立编址方式时，存储单元和I/O 设备靠不同的指令格式区分，访问I/O 设备端口需要单独设置指令，A错误，B 正确;按照数据传送方式，I/O 接口可以分为并行接口和串行接口， C 错误;采用统一编址方式时，存储单元和I/O 设备靠不同地址来区分，D 错误。故本题选B。

第 5 题
关于I/O 接口的I/O 逻辑说法错误的是（ ）
  1. A．不同I/O 接口的I/O 端口不重复，各I/O 逻辑同时对地址线上的地址进行译码，分辨出此次传输是否属于自己
  2. B．通过控制线的读/写信号来对地址标明的I/O 端口进行读写
  3. C．对控制寄存器的I/O 命令字进行译码，对外设发出具体的控制
  4. D．采集外设的状态，并向通过控制线向CPU 反馈设备状态信息以及发出中断请求
答案与解析

答案：D

A 正确，如果不同I/O 接口的端口编号相同，那么无法分辨I/O 指令中的地址属于哪个I/O 接口，所以不同I/O 接口的I/O 端口不重复，对地址译码是I/O 逻辑实现的功能之一。 B 正确，定位好具体的IO端口后，再根据读写信号（比如IN指令是读信号，OUT指令是写信号）来进行及具体输入输出。 C 正确，CPU 通过数据线向控制寄存器写入I/O 命令字，I/O 逻辑接着会对I/O 命令字进行译码，对外设发出对应操作命令。 D 错误，状态信息也是通过数据线传输的（I/O 接口→CPU 寄存器），状态、控制寄存器通常共用一个。中断信号是通过控制线传输的。（IO 接口IRQi 中断请求控制线→中断控制器）。

在下列关于各种I/O 控制方式的说法中，错误的是（ ）
  1. A．程序直接控制I/O 方式适用于结构简单、只需少量硬件的电路，不需要设备驱动程序来完成数据的传输工作

第 8 题
在接收和处理一个输入设备中断的过程中，不是由硬件来完成的工作是（ ）
  1. A．判断产生中断的类型
  2. B．CPU 的特权级由用户态切换到内核态
  3. C．主机获取设备输入
  4. D．保存用户程序断点和PSW

答案：C

中断发生时，I/O 设备会从对应的引脚向CPU 传送中断，CPU 接受到中断后会从用户态转化为内核态并执行中断隐指令，这些过程都是由硬件来完成的，所以A、B、D 不选。对于C选项，唤醒设备驱动程序实际上是包含两个动作：获取输入设备的输入参数需要依靠设备驱动程序，设备驱动程序属于软件部分，因此选C。

第 9 题
下列关于DMA 的叙述中，正确的有（ ）
  1. A．DMA 在CPU 和I/O 设备之间建立一条直接数据通路
  2. B．DMA 是一个专门负责输入/输出的处理机
  3. C．I/O 过程由DMA 控制器进行完成，CPU 只需要在预处理和后处理阶段进行干预

答案：C

A 错误，DMA 在主存和I/O 设备之间建立一条直接数据通路。 B 错误，DMA并不是处理机，只能单方面受CPU控制。 D 错误，DMA方式中，数据传输过程由DMA控制器进行控制，不需要CPU 介入的，但是数据传输的预处理和后处理阶段都需要CPU的干预，DMA需要CPU在预处理时指出所取数据的地址与长度。

第 10 题
已知磁盘采用DMA 方式进行数据传送，若用户进程P 通过系统调用向磁盘发起了读命令，则下列哪个时间点磁盘数据恰好已经进入内核缓冲区（）
  1. A．进程P 被阻塞时
  2. B．CPU 接收到DMA 中断时
  3. C．DMA 中断处理完毕时
  4. D．系统调用完成时
答案与解析

答案：B

在DMA 方式中，由DMA 控制器控制数据在I/O 设备和内核区内存间的传输。进程P 在系统调用中向磁盘发起读命令后阻塞，DMA 控制器通过周期挪用等方式向内存传输磁盘数据当DMA字计数归零，块数据传输到内核区内存的缓冲区后，DMA 发起中断请求，CPU 响应该中断请求并进行中断处理，唤醒阻塞的进程P;只有进程调度导致P 进程上处理机，进程P 完成系统调用后处理，将用户需要的数据从内核缓冲区加载到用户空间，再返回用户态。故B 正确。注意：中断方式下，中断服务程序完成时，数据才进入内核缓冲区。想想为什么？

第 11 题
进程执行系统调用从键盘获取一个字符的输入而被阻塞，当用户在键盘上键入一个字符时，系统的正确处理流程是（）。
  1. A．键盘硬件→中断处理程序→设备驱动程序→进程调度→系统调用返回→用户程序
  2. B．键盘硬件→设备驱动程序→中断处理程序→系统调用返回→进程调度→用户程序
  3. C．键盘硬件→系统调用返回→设备驱动程序→中断处理程序→进程调度→用户程序
  4. D．键盘硬件→中断处理程序→系统调用返回→设备驱动程序→进程调度→用户程序
答案与解析

答案：A

当一个进程因执行系统调用（例如，请求键盘输入）而被阻塞后，等待用户输入字符，其后的处理流程如下：键盘硬件：用户在键盘上键入一个字符。键盘硬件检测到按键，生成相应的编码，并将其存入键盘控制器的内部寄存器中。中断处理程序：键盘控制器向CPU 发出一个中断请求。CPU 响应中断，暂停当前执行的程序（如果CPU 正处于空闲状态，则直接响应；如果正在执行其他进程或内核代码，则根据中断屏蔽和优先级决定何时响应），保存当前现场，然后转去执行操作系统内核中预设的键盘中断处理程序。设备驱动程序：中断处理程序会调用键盘的设备驱动程序。设备驱动程序从键盘控制器读取输入的字符数据，可能会进行一些转换（例如，从扫描码转换成ASCII 码），然后通常会将这个字符放入操作系统内核维护的一个输入缓冲区（例如，终端缓冲区或行缓冲）。此时，由于等待该输入的进程之前是被阻塞的，设备驱动程序（或中断处理程序的一部分）会唤醒这个等待输入的进程，将其状态从阻塞态变为就绪态，并放入就绪队列。进程调度：当中断处理和设备驱动程序的相关工作完成后（通常中断处理程序执行时间很短），如果被唤醒的进程的优先级足够高，或者当前没有其他更高优先级的进程在运行，操作系统的进程调度程序可能会选择这个被唤醒的进程投入运行。也可能在中断返回后，继续执行之前被中断的进程，而被唤醒的进程只是进入了就绪队列。系统调用返回：当被唤醒的进程（即原先请求输入的进程）再次获得CPU 并被调度执行时，它会从之前系统调用的阻塞点继续执行。系统调用处理程序此时可以从内核的输入缓冲区中获取到用户输入的字符，并将这个字符作为系统调用的结果返回给用户程序。CPU 从内核态切换回用户态。用户程序：用户程序获得系统调用返回的字符，继续执行后续逻辑。综上所述，选A。

第 13 题
设备驱动程序主要是指在请求I/O 的进程与设备控制器之间的一个通信和转化程序，下列有关于设备驱动程序的特点中，说法错误的是（）。
  1. A．驱动程序与设备控制器和IO 设备的硬件特性密切相关
  2. B．设备驱动程序应允许可重入，即允许多个进程进行访问但不允许任何进程修改
  3. C．设备驱动程序应允许系统调用

答案：C

以下设备管理工作中，适合由设备独立性软件来完成的有（ ）

Ⅰ．缓和CPU 与I/O 设备间速度不匹配的矛盾
Ⅱ．减少对I/O 中断的频率，放宽对CPU 中断响应时间的限制
Ⅲ．解决数据粒度不匹配的问题
Ⅳ．提高CPU 和I/O 设备之间的并行性
  1. A．Ⅰ、Ⅱ、Ⅲ

  3. C．Ⅱ、Ⅲ、Ⅳ
  4. D．Ⅰ、Ⅱ、Ⅲ、Ⅳ

某操作系统采用双缓冲区传送磁盘上的数据。设一次从磁盘将数据传送到缓冲区的时间为T1，一次将缓冲区中的数据传送到用户区所用的时间可忽略不计，CPU 处理一次数据的时间为T2，读入并处理该数据共重复n 次该过程，需要的总时间为（ ）。
  1. A．n(T1+T2)
  2. B．nT2 +T1
  3. C．nT1+T2
  4. D．(n-1)max(T1，T2)+T1+T2
答案与解析

答案：D

本题需分情况讨论：如果T2>T1，即CPU 处理数据比数据传送慢，那么磁盘将数据传送到缓冲区，再传送到用户区进行处理，除了第一次需要花的时间T1+T2，剩余数据可视为CPU进行连续处理，共花费时间(n-1)T2，读入并处理所用的总时间为T1+nT2，。如果T2<T1，即CPU 处理数据比数据传送快，此时除了第一次可视为I/O连续输入，磁盘将数据传送到缓冲区，与缓冲区中的数据传送到用户区及CPU 处理数据，两者可视为并行执行，那么花费时间主要取决于磁盘将数据传送到缓冲区所用的时间，前n-1 次所花的时间共为(n-1)T1，而最后一次的时间T1 完成后，还要花时间从缓冲区传送到用户区，且CPU还要处理，即要加上时间T2，读入并处理所用的总时间为nT1+T2。综上所述，总时间为(n-1)max(T1，T2)+T1+T2。

第 27 题
设备分配程序为用户进程分配设备的过程通常是（ ）
  1. A．先分配设备，再分配设备控制器，最后分配通道
  2. B．先分配设备控制器，再分配设备，最后分配通道
  3. C．先分配通道，再分配设备，最后分配设备控制器
  4. D．先分配通道，再分配设备控制器，最后分配设备
答案与解析

答案：A

通道控制设备控制器，设备控制器控制设备。当进程提出IO 请求后，系统的设备分配程序可按以下步骤进行设备分配：
①分配设备。首先根据I/O 请求中的物理设备名（一般进程是提供逻辑设备名，通过逻辑设备表映射成物理设备名），查找系统设备表SDT，从中找出该设备的设备控制表DCT，再根据DCT 中的设备状态字段获知该设备是否正忙。若忙，则将请求I/O 的进程的PCB 挂在设备队列上。否则，按照一定的算法计算本次设备分配的安全性。如果不会导致系统进入不安全状态，则将设备分配给请求进程。否则，仍将其PCB 插入设备等待队列。
②分配控制器。在系统把设备分配给请求I/O 的进程后，再到其DCT 中找出与该设备连接的控制器的控制器控制表COCT，从COCT 的状态字段中可知该控制器是否正忙。若忙，则将请求IO 进程的PCB 挂在该控制器的等待队列上。否则，将该控制器分配给进程。
③分配通道。在该COCT 中又可找到与该控制器连接的通道的通道控制表CHCT。根据CHCT内的状态信息可知该通道是否正忙。若忙，则将请求IO 的进程挂在该通道的等待队列上;否则，将该通道分配给进程。只有在设备、控制器和通道三者都分配成功时，这次的设备分配才算成功。然后，便可启动该I/O 设备进行数据传送。

答案：D

Ⅰ错误，SPOOLing 系统的核心组成部分包括位于磁盘上的输入井和输出井，以及位于内存中的输入缓冲区、输出缓冲区、输入进程和输出进程。因此，并非所有组成部分都在内存中，磁盘上的井是关键。 Ⅱ错误，SPOOLing 技术是在多道程序设计技术的基础上发展起来的。它需要系统能够并发地执行用户作业、输入进程和输出进程。在单道批处理系统中，内存中只有一个程序在运行，无法实现这种并行操作。 Ⅲ错误，SPOOLing 技术是将低速输入设备的数据先传送到高速磁盘上的输入井，或者将用户程序要输出的数据先送到磁盘上的输出井。当CPU 需要输入数据时，是从输入井（磁盘）读取；当需要输出数据时，是输出到输出井（磁盘）。输入设备的数据通过输入缓冲区进入输入井，输出井的数据通过输出缓冲区送到输出设备。输入/输出井与输入/输出设备之间并不是直接连接，而是通过内存中的缓冲区以及输入/输出进程进行中转。其目的是利用磁盘的高速特性来匹配CPU 的速度，而不是输入/输出井与慢速设备直连。 Ⅳ错误，SPOOLing 技术是对脱机输入/输出系统中外围控制机功能的一种模拟。它是在主机的直接控制下，利用多道程序中的专门进程（输入进程和输出进程）来模拟外围控制机的功能，从而实现在联机情况下进行的同时外围操作，因此不需要物理上的外围机支持。综上所述，选D。
