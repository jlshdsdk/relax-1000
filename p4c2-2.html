第 31 题
下列关于数据通信方式的描述中，正确的是？
  1. A．对讲机的工作方式是典型的单向通信，因为同一时间只能有一个人讲话。
  2. B．传统的广播电视系统（如无线电广播或地面电视广播）采用的是半双工通信方式。
  3. C．如果通信双方在任何时刻都可以同时发送和接收数据，则称这种通信方式为全双工通信。
  4. D．在使用集线器连接的以太网中，由于存在碰撞检测机制，所以设备间采用的是全双工通信。
答案与解析

答案：C

对讲机是半双工通信，允许双向通信但不能同时进行，故A 错误。传统广播电视是单工通信，信息只能单向从发射台传向接收机，故B 错误。全双工通信允许通信双方在任何时刻同时发送和接收数据，C正确。集线器连接的以太网构成一个冲突域，所有设备共享带宽，采用CSMA/CD 机制，工作在半双工模式，D 错误。交换机连接的点对点链路可以工作在全双工模式。

第 32 题
在导向传输介质中，抗电磁干扰能力最强、传输带宽最高、传输距离最远的是？
  1. A．非屏蔽双绞线（UTP）
  2. B．屏蔽双绞线（STP）
  3. C．同轴电缆
  4. D．光纤
答案与解析

答案：D

光纤通过光脉冲传输数据，其材料（玻璃或塑料）不导电，因此完全不受电磁干扰（EMI）和射频干扰（RFI）的影响。光纤还具有极高的带宽潜力和非常低的信号衰减，使其能够支持长距离高速传输。

第 33 题
与多模光纤相比，单模光纤能够支持更长传输距离和更高传输速率的主要原因是？
  1. A．单模光纤的纤芯直径更大，能传输更多光能。
  2. B．单模光纤的光源成本更低，易于驱动。
  3. C．单模光纤只允许单一模式的光传播，有效消除了模式色散。
  4. D．单模光纤的数值孔径更大，光耦合效率更高。
答案与解析

答案：C

单模光纤的纤芯直径非常小，使得光信号只能沿着纤芯的轴心以单一路径（模式）传播，从而避免了多模光纤中因多种模式光信号沿不同路径、以不同速度传播而引起的模式色散。模式色散会导致光脉冲展宽，限制了传输速率和距离。消除了模式色散是单模光纤能够支持更长距离和更高速率的关键。

第 34 题
在物理层接口特性中，规定了物理层接口电缆上各条信号线的功能（如数据线、控制线、时钟线等）的是其哪种特性？
  1. A．机械特性
  2. B．电气特性
  3. C．功能特性
  4. D．过程特性
答案与解析

答案：C

物理层接口的功能特性指明了接口各条信号线（引脚）的用途，例如哪些线用于发送数据、哪些用于接收数据、哪些用于提供时钟信号、哪些用于控制等。

第 35 题
一个物理层设备（如网卡）在发送数据前，需要先检测信道是否空闲，若空闲则发送一个特定的请求同步序列，等待对方回应一个同步确认序列后才开始正式数据传输。这一系列交互的定义属于物理层接口的？
  1. A．机械特性
  2. B．电气特性
  3. C．功能特性
  4. D．过程特性
答案与解析

答案：D

过程特性定义了在物理连接的建立、维持和释放过程中，各种事件发生的合法顺序。题目描述的“检测信道->发送同步请求->等待同步确认->开始传输”是一个典型的事件序列，符合过程特性的定义。

第 36 题
某物理层接口规定其连接器必须采用DB-9 型插头，并且明确了9 个引脚中哪几个用于发送数据（TD）、接收数据（RD）、接地（GND）等。这分别体现了该接口的哪些特性？
  1. A．机械特性和电气特性
  2. B．机械特性和功能特性
  3. C．电气特性和功能特性
  4. D．功能特性和过程特性

答案：B

规定连接器的型号（如DB-9）属于机械特性，因为它定义了接口的物理形状、尺寸和引脚排列。明确各个引脚的功能（如TD 用于发送数据，RD 用于接收数据）则属于功能特性。

第 37 题
下列选项中，不属于物理层接口规范定义范畴的是？
  1. A．接口连接器的引脚功能定义
  2. B．信号在接口电缆上传输时的最大速率和距离限制

第 38 题
在一个使用集线器的10BaseT 局域网中，各台计算机连接到集线器上，以此网络的拓扑结构为 （）。
  1. A．各结点之间的物理连接和逻辑连接都是星状拓扑。
  2. B．物理连接是星状拓扑，逻辑连接是总线状拓扑。
  3. C．物理连接是总线状拓扑；逻辑连接是星状拓扑。

第 39 题
在一个10BASE-T 以太网中，使用一个集线器连接了若干台主机。如果其中一台主机发送数据帧时，下列说法正确的是？
  1. A．只有目的主机能接收到该数据帧。
  2. B．集线器会根据目的MAC 地址将帧转发给特定端口。
  3. C．所有连接到该集线器的其他主机都会接收到该数据帧。
  4. D．集线器会放大并重新定时信号，但不会转发到所有除源主机所在端口外的端口。
答案与解析

答案：C

集线器工作在物理层，它将接收到的信号进行放大和整形，然后将其广播到除输入端口外的所有其他端口。集线器不识别帧的MAC 地址，因此无法进行定向转发。所有连接到集线器的主机（在同一个冲突域内）都会收到该数据帧，由各主机的网卡判断是否是发给自己的。

第 40 题
中继器工作时，它连接的两个网段必须具有相同的（ ）。
  1. A．网络层协议
  2. B．MAC 地址格式
  3. C．数据传输速率
  4. D．逻辑拓扑结构
答案与解析

答案：C

中继器是物理层设备，它对信号进行再生和放大，以延长网络传输距离。它连接的两个网段必须在物理层规范上完全相同，包括数据传输速率、信号编码方式等。如果速率不同，中继器无法正确处理信号。

第 41 题
使用中继器连接LAN 的粗同轴电缆段数是有限制的，任何两个数据终端设备允许的传输通路中可使用的中继器个数最多是（）。
  1. A．1 个
  2. B．3 个
  3. C．4 个
  4. D．5 个
答案与解析

答案：C

网络标准中对信号的延迟范围做了具体的规定，中继器只能在此规定范围内进行有效的工作，否则会引起网络故障。例如，在采用粗同轴电缆的10BASE5以太网规范中，互相串联的中继器连接必须遵守“5-4-3规则”(4 中继器限制)，即用4 个中继器连接5 个网段，其中只有3 个网段可以连接站点。

第 42 题
可以让模拟信号和数字信号传播更远的设备，分别是（ ）。
  1. A．中继器，放大器
  2. B．放大器，中继器
  3. C．交换机，放大器
  4. D．集线器，放大器
答案与解析

答案：B

信号在传输过程中会因为介质的物理特性而衰减。为了能将信号传输得更远，就需要在线路中间对信号进行增强。对于模拟信号，使其传播更远的设备是放大器，放大器的作用是将衰减的模拟信号的能量放大。对于数字信号，使其传播更远的设备是中继器，中继器对失真的数字信号进行“再生”和“还原”，而不是简单的放大。

第 43 题
在10Mbps 以太网标准中，规定了最小帧长为64 字节。如果一个站点发送了一个小于64 字节的帧，集线器会如何处理这个帧？
  1. A．丢弃该帧，因为它太短。
  2. B．自动填充该帧到64 字节再转发。
  3. C．正常放大并转发该短帧。
  4. D．向发送端发送一个错误报告。
答案与解析

答案：C

集线器作为物理层设备，它不对数据帧的内容进行检查，包括帧的长度。它接收到比特流后，会进行信号放大和再生，然后将其转发出去。处理短帧（或runt frame）是更高层（如数据链路层，由网卡或驱动程序负责填充）或接收端的事情，集线器本身会按原样转发它接收到的比特信号。

第 44 题
现有五个主机连接在一个10Mbps 的集线器上，在理想情况下当这5 台计算机都想尽可能快地对外发送数据时，从整个集线器角度看，其总的输出数据吞吐量上限最接近？
  1. A．2 Mbps
  2. B．5 Mbps
  3. C．10 Mbps
  4. D．50 Mbps
答案与解析

答案：C

连接在集线器上的所有主机共享集线器的总带宽。对于一个10Mbps 的集线器，无论连接多少台主机，它们共同分享这10Mbps 的带宽。由于集线器是半双工工作方式，并且构成一个冲突域，在任何时刻只有一个主机可以成功发送数据。因此，从整个集线器（冲突域）的角度来看，其总的输出数据吞吐量上限就是该集线器的额定速率，即10Mbps。

第 45 题
现有N 个主机连接在一个10Mb/s 的集线器上，这些主机平均共享信道。当N 从1 逐渐增加至10 时，对于每一个主机而言，其获得的平均带宽理论上如何变化？若同时考虑到碰撞的影响，实际获得的平均带宽又会如何变化？
  1. A．理论上始终为10Mbps/N；实际上下降得更快。
  2. B．理论上始终为10Mbps/N；实际上下降得更慢。
  3. C．理论上保持10Mbps 不变；实际下降。
  4. D．理论上始终为10Mbps/N；实际上与理论一致。
答案与解析

答案：A

理论上，如果N 个主机完全平均地、无冲突地共享10Mb/s 的带宽，则每个主机获得的平均带宽为(10/N) Mb/s。当N=1 时，带宽为10Mbps；当N=10 时，带宽为1Mbps。这个变化趋势是随着N 的增加而减少。实际中需要考虑碰撞，集线器环境是一个冲突域。当N 增加时，多个主机同时发送数据的概率增大，导致数据帧碰撞的几率也随之增加。发生碰撞后，相关主机必须等待一个随机时间后重传，这会浪费信道带宽。因此，随着N 的增加，碰撞的负面影响会越来越显著，导致每个主机实际获得的平均带宽会低于理论上的(10/N) Mb/s，并且下降的速率会因为碰撞的加剧而比理论情况更快。 【答案速对】 AACDBCCBDBBCBBACACCACBBDDCDDACDBCABDDBACBDCBCDDDACCADAABDCBBCCCBBBCBCCCCAABDBDDBCCCBCCAAACCDCDCC
