第 61 题
3 对括号，合法的括号序列有（ ）种。
  1. A．3
  2. B．4
  3. C．5
  4. D．6
答案与解析

答案：C

本题是栈的应用考察。左括号视为入栈，右括号视为出栈，本题就变成了问3 个元素入栈有多少种不同的出栈序列个数。答案是卡特兰数，n=3的卡特兰数是5。也可自己枚举： ((()))、(()())、(())()、()(())、()()()。

第 62 题
已知初始为空的队列Q 的一端仅能进行出队操作，另外一端既能进行入队操作又能进行出队操作，入队后可立马出队。若Q 的入队序列是1、2、3、4、5 则不能得到的出队序列是（ ）。
  1. A．1、2、3、4、5
  2. B．5、4、3、2、1
  3. C．2、1、5、4、3
  4. D．5、3、1、2、4
答案与解析

答案：D

A 正确，所有元素依次入队，再从左端依次出队。B 正确，所有元素依次入队，再从右端依次出队。C 正确，1、2 入队，右边出2，左边出1，3、4、5 依次入队，右侧依次出队5、 4、3，正确。D 错误，5 第一个出队，说明所有元素都依次入队了，此时队列还剩1、2、3、4。无论左右都无法出3。

第 63 题
设主串T="abaaabcaabaababca"，模式串S="aabaab"，采用修正的KMP 算法进行模式匹配，到匹配成功时为止，在匹配过程中进行的单个字符间的比较次数是（）。
  1. A．12
  2. B．13
  3. C．14
  4. D．15
答案与解析

答案：C

下标从0 开始编号，先求next 数组=[-1,0,1,0,1,2]，再求nextval 数组=[- 1,-1,1,-1,-1,1]。用下标i 表示主串T 位置，j 表示模式串S 位置，每次失配时，根据nextval 来修改j 的回溯位置。当i=j=1 时，T[1]=’b’≠S[1]=’a’，一共比较2 次，第一次失配后，i=2,j=0; 当i=4，j=2 时，T[4]=’a’≠S[2]=’b’，一共比较3 次，第二次失配后，i=4,j=1; 当i=6，j=3 时，T[6]=’c’≠S[3]=’a’，一共比较3 次，第三次失配后，i=7,j=0; 当i=12，j=5 时，匹配成功，一共比较6 次。总计比较2+3+3+6=14 次，答案选C。

第 64 题
下列关于队列说法中正确的有（ ）。 I.循环队列可以解决“假溢出”问题II.循环队列一定是顺序存储结构III.链式队列（单链表）队头设置在链头/链尾出队时间复杂度都是O(1) IV.链式队列（单链表）可以根据队尾指针和队头指针计算出队列长度
  1. A．I、III
  2. B．I、II
  3. C．II、III
  4. D．III、IV
答案与解析

答案：B

I 正确，普通顺序队列（数组实现、非循环）中，元素不断出队导致队头front后移，数组前部出现大量空闲空间；但队尾指针rear已到达数组最大下标，无法继续入队。数组明明未满，却判定为“溢出”，这就是假溢出。循环队列将一维数组在逻辑上首尾相连，利用取模运算 (rear+1)%MaxSize让队尾指针走到数组末尾后回到数组头部，复用前部空闲空间，彻底解决假溢出。II 正确，教材上队列的两种存储结构分别为循环队列和链式队列，所以说循环队列本身也是一种存储结构。III 错误，链式队列，队头一般设置在链表头部，出队涉及到删除操作，如果设置在链表尾部，删除单链表尾部元素的时间复杂度为O(n)；IV 错误，逻辑上连续的两个结点的指针在物理上不一定连续，链式存储是动态申请结点空间，在内存是不连续的，所以无法通过指针做差计算队列长度。答案选B。
