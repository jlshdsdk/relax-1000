第 31 题
用户程序执行陷入指令触发系统调用后，CPU会从用户态切换到内核态。在这个切换及准备执行内核服务例程的过程中，下列操作中由硬件（中断隐指令）自动完成的是（）。
I. 将CPU 模式从用户态修改为内核态
II. 保存通用寄存器的内容到内核栈
III. 保存程序计数器（PC）和程序状态字（PSW）
IV. 根据系统调用号查找并跳转到系统调用服务例程
  1. A．I、III
  2. B．I、II、III
  3. C．II、IV
  4. D． I、II、III、IV
答案与解析

答案：A

当陷入指令执行引发内中断时：I、III正确（硬件完成）：硬件的中断隐指令会自动将CPU 状态改为内核态，并自动将断点（PC）和程序状态字（PSW）压入内核栈保存。 II错误（软件完成）：通用寄存器（如EAX, EBX 等）的保存是由操作系统的陷入处理程序（软件代码）通过执行压栈指令来完成的，以防后续的内核代码覆盖用户态的寄存器现场。 IV错误（软件完成）：硬件只负责跳转到系统调用的统一总入口（如system_call）。根据系统调用号查表并跳转到具体的服务例程，是由操作系统内核代码（软件）完成的。综上，由硬件自动完成的仅有I和III，故选A。

第 32 题
在支持多任务的操作系统中，时钟中断处理程序执行完毕后，发现当前进程时间片已用完，需要进行进程切换。下列关于此过程的叙述中，错误的是（）。
  1. A． 时钟中断发生时，CPU 不一定从用户态切换到内核态
  2. B． 进程切换完成后，新进程一定在用户态开始执行
  3. C． 进程切换过程中需要修改PCB 中的寄存器信息
  4. D． 时钟中断处理程序和进程调度程序都在内核态执行
答案与解析

答案：B

先看B，错误。本题考察对进程切换时机和状态的精确理解。A 正确，时钟中断不一定发生在用户态，也可以是内核态下发生，比如中断嵌套。B 错误，这是本题的陷阱所在。进程切换完成后，新调度的进程不一定在用户态开始执行。如果这个新进程之前是在内核态中被中断的（例如，它正在执行一个长耗时的系统调用等待外部设备I/O 完成），那么当它被换下并重新调度回来时，它将在内核态继续执行其被中断的系统调用代码，直到该系统调用完成才会返回到用户态。C 正确，进程切换的本质就是保存当前进程的CPU 上下文（包括寄存器的值）到其PCB 中，然后从新进程的PCB中恢复其上下文。D 正确，时钟中断处理程序和进程调度程序都是操作系统内核的一部分，它们的执行当然在内核态。

第 33 题
下列关于系统调用中使用的陷入指令（trap 指令/访管指令）的叙述中，正确的是（ ）。
  1. A． 陷入指令是一条特权指令，只能在内核态下执行
  2. B． 执行陷入指令后，硬件保存的断点通常是该陷入指令本身的地址，以便返回后重新执行
  3. C． 陷入指令会引发一个内部异常（软中断），从而迫使CPU 从用户态切换到内核态
  4. D． 不同的系统调用需要使用不同的陷入指令来触发，以便硬件直接识别系统调用类型
答案与解析

答案：C

陷入指令（如int $0x80或syscall）本质上是在用户态执行的一条特殊指令，执行后会立即引发一个内中断（软中断/访管中断），硬件响应此中断从而将CPU 切换到核心态。 A 项错误。陷入指令必须在用户态执行，它是用户程序主动请求内核服务的唯一“合法入口”。如果它是特权指令，用户程序就无权执行，系统调用也就无从发起了。 B 项错误。系统调用是“陷阱（Trap）”，属于主动请求，服务完成后应该继续执行用户程序的下一条指令，因此保存的断点是下一条指令的地址。只有像“缺页异常”这种故障（Fault），保存的才是当前指令地址（以便页面调入后重新执行该指令）。 D 项错误。操作系统通常提供统一的陷入指令作为系统调用的总入口。区分不同系统调用靠的是存放在寄存器中的系统调用号，而不是靠不同的陷入指令。

第 36 题
下列关于系统调用封装函数（如write()）在机器级代码实现上的叙述，错误的是（ ）。
  1. A． 封装函数对应的机器指令序列通常由若干条传送指令和一条陷阱指令组成
  2. B． 系统调用所需的参数和系统调用号均通过通用寄存器传递，而不是主要通过栈传递
  3. C． 不同的系统调用在执行陷阱指令时，硬件会直接根据其系统调用号在中断向量表中检索并跳转到各自对应的内核服务例程
  4. D． 处理器执行完陷入指令后，程序计数器PC 将指向系统调用处理程序的首地址
答案与解析

答案：C

A正确：封装函数有一个统一结构：先用若干条传送指令（mov）把参数和系统调用号送入指定的通用寄存器，紧跟上一条陷阱指令（如int $0x80）陷入内核。 B正确：系统调用为了提高效率，通过寄存器传递参数（如EAX放调用号，EBX、ECX等放参数），这与普通过程调用（CALL指令）默认用栈传参的机制不同。 C错误（考点核心）：硬件查表阶段：所有的系统调用在执行陷阱指令时，向硬件提供的都是同一个中断类型号（如X86 中的0x80）。硬件（CPU）根据这个统一的类型号，去检索中断向量表，跳转到操作系统内核的统一入口——即系统调用处理程序system_call的首地址。软件查表阶段：进入内核态并执行system_call后，操作系统内核（软件）才会读取寄存器（如EAX）中的系统调用号，并以此为索引去检索系统调用表（跳转表），最终跳转到具体的内核服务例程（如sys_write）。结论：硬件并不会直接用系统调用号去查中断向量表，两者的映射级数和查表主体不同。 D正确：陷入指令的执行会触发软中断，硬件响应中断后，PC 会被赋值为中断向量表里0x80号表项对应的地址，即系统调用处理程序system_call的第一条指令

第 39 题
下列关于操作系统结构的说法中，正确的是（ ）。
  1. A． 分层结构中，任意上层都可以直接调用下层服务，不存在层级限制
  2. B． 模块化结构将所有服务都置于内核空间，以保证最高的执行效率
  3. C． 微内核结构通过将大部分服务移至用户空间，以换取更高的系统可靠性
  4. D． 外核向应用程序提供与传统操作系统相同的、丰富的抽象接口，以简化编程
答案与解析

答案：C

C 选项准确地概括了微内核架构的核心设计思想。通过将文件系统、设备驱动等非核心服务移出内核，运行在用户态的独立进程中，微内核实现了服务间的良好隔离。这意味着即使某个服务进程崩溃，也不会导致整个操作系统宕机，从而极大地提升了系统的可靠性。这正是微内核相对于宏内核的主要优势之一，也是其设计的根本出发点。 A 项错误：此说法颠倒了分层结构的依赖关系。在分层结构中，第i 层只能使用第i-1 层提供的服务，而不能直接调用更低层的服务，也不能被更高层直接调用。每一层都是其下一层的服务使用者，同时也是其上一层的服务提供者。因此，A 项的描述是错误的。 B 项错误：此说法混淆了模块化结构与宏内核结构的特点。模块化结构确实将操作系统视为一个整体，但其精髓在于将这个整体分解为可独立加载的模块。这些模块可以位于内核空间，也可以以某种形式在用户空间运行，其核心优势在于灵活性和可维护性，而非单纯为了追求执行效率。宏内核之所以效率高，是因为其所有组件都在同一个地址空间，通过函数调用通信。模块化结构并不必然保证最高的执行效率。 D 项错误：此说法完全误解了外核的定义。外核的设计哲学恰恰相反，它不向应用提供高级抽象接口，而是将硬件资源（如内存页、磁盘块）的管理权部分或全部交还给应用程序。应用程序需要自己编写代码来管理这些底层资源，实现所需的抽象（即所谓的“库操作系统”）。这样做是为了消除中间抽象层带来的性能开销，并赋予应用最大程度的控制权。因此，D 项的说法是错误的。

下列关于分层式结构操作系统的说法中，错误的是（ ）。

  2. B．各层次间的依赖性低
  3. C．各层次可以互相调用

第 41 题
下列关于宏内核与模块化结构的说法中，错误的是（ ）。
  1. A．模块化结构的可靠性一定高于宏内核
  2. B．两者均将核心服务置于内核空间运行
  3. C．模块化结构支持运行时动态加载/卸载功能模块，而传统宏内核不支持
  4. D．两者的服务间通信均可通过内核空间内的函数调用完成
答案与解析

答案：A

A 错误：“可靠性一定高于”表述绝对化。模块化结构虽通过模块隔离降低了部分耦合，但模块仍运行在内核空间，一个模块的错误仍可能破坏内核数据结构导致系统崩溃。其可靠性仅略优于传统宏内核，但远不及微内核，且“一定高于”不符合实际。 B 正确：宏内核和模块化结构都属于“大内核”范畴，核心服务（进程管理、内存管理、文件系统等）均运行在内核空间，这是它们与微内核的根本区别。 C 正确：模块化结构的核心优势之一是支持可加载内核模块，允许在系统运行时动态添加或移除功能，而传统宏内核所有功能必须在编译时静态链接，无法运行时动态调整。 D 正确：由于两者服务均在内核空间，服务间通信可通过直接的函数调用完成，无需跨地址空间的消息传递，因此性能较高。

第 42 题
对于宏内核和微内核操作系统设计的区别，下面说法正确的是（ ）。
  1. A．宏内核设计下所有内核模块都运行在内核态，微内核设计下所有内核模块都运行在用户态
  2. B．宏内核设计下不同模块间通信主要通过过程调用，而微内核下各用户态服务组件间主要通过消息传递进行通信
  3. C．宏内核相较微内核设计下特权级切换更为频繁

在计算机系统中，操作系统通常存储在（ ）上，计算机开机后，操作系统最终被加载到 （）。

第 45 题
在计算机系统中，操作系统的引导程序一般存储在哪个区域?（ ）。
  1. A．硬盘
  2. B．cache
  3. C．BIOS 芯片
  4. D．内存
答案与解析

答案：A

BIOS(Basic Input Output System，基本输入输出系统)是一组固化到计算机主板上一个ROM 芯片上的程序，它保存着计算机中最重要的自诊断程序、CMOS 设置程序、基本输入输出程序、系统设置信息、开机加电自检程序和系统启动自举程序，其主要功能是为计算机提供最底层的、最直接的硬件设置和控制。操作系统的引导分两步：主引导扇区位MBR 于硬盘的0 磁道0 柱面1 扇区，共512bytes，由三大部分组成：
①硬盘主引导记录MBR（Master Boot Record）占446bytes
②分区表DPT（Disk Partition Table）占64bytes
③硬盘有效标志（Magic Number）占2bytes。分区引导记录PBR（Partition Boot Record），也常被称为分区引导扇区（Partition Boot Sector）。在操作系统引导过程中，PBR 是存储在磁盘分区的第一个扇区中的数据结构，它包含了分区的引导程序代码和引导加载程序的相关信息。两个引导程序都在磁盘区域，一般来说，PBR是OS的实际引导程序，如果同时出现MBR和PBR，操作系统的引导程序位置应选PBR。本题选A。

第 46 题
关于计算机开机引导与初始化的全过程，下列说法中错误的是（）。
  1. A． BIOS 引导程序执行时，CPU 处于实模式，此时由BIOS 在主存的特定区域建立中断向量表
  2. B． 磁盘引导程序（MBR 内）利用BIOS 提供的中断服务程序将分区引导程序（PBR）读入内存
  3. C． 操作系统内核进行初始化时，会建立保护模式下的中断描述符表（IDT）以替代原有中断向量表
  4. D． 逻辑格式化（高级格式化）核心任务是将操作系统内核映像文件复制到硬盘的指定活动分区中
答案与解析

答案：D

A 对，开机后系统首先在实地址模式下工作，BIOS 程序首先检测显卡、键盘、内存等，并在主存的00000H~003FFH 区域建立中断向量表，同时，在中断向量所指的主存区域建立相应的中断服务程序B 对：此时操作系统还没加载，没有磁盘驱动。MBR 中的磁盘引导程序只能调用固化在ROM 中的BIOS 中断来读取硬盘后续扇区。 C 对：操作系统内核接管系统后，会从实模式切换到保护模式，此时不再使用BIOS的中断向量表，而是建立中断描述符表（即保护模式下的中断向量表）。 D错：逻辑格式化的核心任务是创建文件系统结构（如写入超级块、i 节点表、空闲空间管理表等）。而“将操作系统内核映像文件复制到硬盘中”是操作系统安装阶段的任务。

第 47 题
操作系统内核被Bootloader 加载到内存后，将开始执行一系列的初始化操作。下列选项中，不属于内核初始化阶段完成的工作是（）。
  1. A． 初始化系统中的中断向量表等内核数据结构
  2. B． 将硬盘上的文件分配表（FAT）或索引节点（inode）读入内存
  3. C． 划分磁盘扇区并建立主引导记录（MBR）

第 48 题
在操作系统的启动过程中，需要执行下列程序：
①自检程序②操作系统③引导程序④引导装入程序其先后顺序为（）。
  1. A．①④③②
  2. B．③②④①
  3. C．①③②④
  4. D．①②③④
答案与解析

答案：A

• 自检程序（POST）：开机时BIOS 固件执行，用于检测CPU、内存、显卡、键盘等硬件是否正常 • 引导装入程序（也叫主引导记录MBR，在磁盘0 磁道0 盘面第1 扇区）：通电自检结束后，加载“实际的引导程序”到内存中，根据分区表加载活动分区，将控制权交给活动分区。引导程序（分区引导记录PBR，活动分区的第一个扇区）：寻找并激活分区根目录下用于引导 • 操作系统的程序。 • 加载操作系统。将操作系统加载进内存中执行。计算机加电启动过程为：自检程序→自举装入程序(引导装入程序)→引导程序→操作系统。本题选A。

第 49 题
下列关于虚拟机的描述中，正确的是（ ）。
  1. A．第一类虚拟机的硬件资源的管理者是宿主操作系统
  2. B．第一类VMM 可以执行最高特权的指令
  3. C．第二类VMM 直接运行在硬件之上，可以直接控制和分配物理资源
  4. D．第一类VMM 相对于第二类VMM 来说，性能更差
答案与解析

答案：B

A 错误，第一类VMM直接运行在物理硬件之上，它自身就是硬件资源的管理者。它上面运行的是客户机操作系统，并不依赖宿主操作系统。 B 正确，第一类VMM直接安装在硬件上，它本身就扮演着操作系统的角色，运行在最高特权级别，负责管理和分配硬件资源给上层的虚拟机。 C 错误，第二类VMM 是作为应用程序运行在宿主操作系统之上的。它不直接运行在硬件之上，而是通过宿主操作系统来间接访问和控制物理资源。 D 错误，通常情况下，第一类VMM 的性能优于第二类VMM。这是因为第一类VMM 直接控制硬件，减少了宿主操作系统带来的开销和指令转换层次。第二类VMM 由于需要通过宿主操作系统间接访问硬件，会引入额外的性能损耗。

第 50 题
下列关于虚拟机的描述中，正确的是（ ）。
  1. A．在第一类VMM 中，真实硬件可以直接在用户态执行虚拟机中的敏感指令
  2. B．第二类VMM 负责把虚拟机程序的地址转换为内存中的物理地址
  3. C．第二类VMM 完全运行在用户态
  4. D．第一类VMM 能直接分配“未抽象”的物理硬件，而第二类VMM 只能分配“抽象化”的物理硬件
答案与解析

答案：D

A 错误，在第一类虚拟机中，当虚拟机操作系统执行了一条CPU 处于内核态才允许执行的指令时，会陷入VMM。在支持虚拟化的CPU 上，VMM 检查这条指令是由虚拟机中的操作系统执行的还是由用户程序执行的。如果是前者，VMM 将安排这条指令功能的正确执行。否则，VMM将模拟真实硬件面对用户态执行敏感指令时的行为。在过去不支持虚拟化的CPU上，真实硬件也不会直接执行虚拟机中的敏感指令，这些敏感指令被转为对VMM 的调用，由VMM 模拟这些指令的功能。而在支持虚拟化的CPU 上，虚拟机管理程序检查这条指令是由虚拟机中的操作系统执行的还是由用户程序执行的。如果是前者，虚拟机管理程序将安排这条指令功能的正确执行。否则，虚拟机管理程序将模拟真实硬件面对用户态执行敏感指令时的行为。 B 错误，第二类VMM 负责把虚拟机程序的虚拟地址转换为宿主操作系统中的虚拟地址（这个虚拟地址在虚拟机os 看来是”物理地址“），再由宿主操作系统转换为物理地址。 C 错误，虽然第二类VMM本身是作为宿主操作系统上的一个应用程序启动和运行的，但为了实现对虚拟机的管理和模拟一些特权操作，它的部分组件或在某些时刻可能需要宿主操作系统的内核态服务或者以某种特权级别运行（例如，通过加载内核模块或利用宿主OS 提供的API）。它不像第一类VMM那样完全取代操作系统而运行在最高特权级，但也不能说它完全运行在用户态而不涉及任何内核态的交互或依赖.它的核心功能（如指令解释、设备模拟）大部分在用户态，但与硬件交互和资源管理离不开宿主OS 内核的支持. D 正确，第一类VMM，直接运行在物理硬件之上。这意味着它可以直接管理和分配真实的、未经过抽象的物理硬件资源给虚拟机.第二类VMM 作为应用程序运行在宿主操作系统之上.它通过宿主操作系统来访问物理硬件，因此它分配给虚拟机的硬件资源通常是经过宿主操作系统抽象和管理的“虚拟”或“抽象化”的物理硬件。

第 51 题
下列关于虚拟机的说法正确的是（ ）。 I．第一类虚拟机的硬件资源的管理者是宿主操作系统II．第二类虚拟机的虚拟机管理程序负责把虚拟机程序的地址转换为内存中的物理地址。 III．第一类虚拟机的敏感指令不一定执行在内核态
  1. A．I、II、III
  2. B．I、II
  3. C．II
  4. D．III
答案与解析

答案：D

第一类虚拟机没有宿主操作系统，硬件资源的管理者是虚拟机管理程序 （VMM），I 错误；第二类虚拟机管理程序负责把虚拟机程序的虚拟地址转换为宿主操作系统中的虚拟地址（这个虚拟地址在虚拟机os 看来是”物理地址“），再由宿主操作系统转换为物理地址，II 错误；第一类虚拟机的非敏感指令执行在ring1 层，而敏感指令执行在ring0 层（内核态）。理想情况下，我们希望敏感指令集等于特权指令集，对于一般RISC处理器，如MIPS，PowerPC以及SPARC，敏感指令就是特权指令，但是x86例外，但是x86 绝大多数的敏感指令是特权指令，但是由部分敏感指令不是特权指令，执行这些指令的时候不会自动trap，而是被VMM 捕获。几乎所有现代CPU 都支持硬件虚拟化，这些不会trap 的敏感指令，是通过允许VMM 捕获并仿真敏感指令来实现的，可以在用户态执行， III 正确。

第 52 题
与微内核操作系统相比，下列关于外核操作系统的说法中，错误的是（ ）。
  1. A． 两者均将文件系统和设备驱动程序作为独立的用户态服务器进程运行
  2. B． 微内核依赖IPC 机制实现用户态服务间的协同，外核则不负责实现高级硬件抽象
  3. C． 微内核将大部分OS 服务移至用户态以提高系统可靠性，外核的核心职责是安全地分配物理硬件资源
  4. D．外核允许应用程序直接管理底层物理资源，因此通常比微内核具有更高的执行效率
答案与解析

答案：A

A 错误：这是微内核与外核最容易混淆的地方。微内核确实将文件系统等作为独立的用户态服务器进程运行；但在外核架构中，文件系统等功能是由应用程序链接的“库操作系统 （LibOS）”提供的，LibOS 与应用程序运行在同一个进程的地址空间内，而不是作为“独立的用户态服务器进程”运行。因此A 的说法错误。 B 正确：微内核架构中，各个功能模块（如文件系统、网络）是相互独立的用户态进程，必须依赖内核提供的进程间通信（IPC）机制来交换数据；而外核的设计哲学是“消除抽象”，它只负责分配物理资源（如物理内存页、磁盘块），不提供虚拟内存、文件系统等高级硬件抽象，这些抽象由应用层的 “库操作系统（LibOS）”来实现。 C 正确：微内核将非核心服务移出内核态，使得某个服务崩溃不会导致整个系统宕机，从而提高了系统的可靠性；外核（Exokernel）顾名思义，其核心职责就是作为硬件资源的保护者，确保多个应用程序能够安全地复用底层物理资源，而不干涉应用如何使用这些资源。 D 正确：微内核最大的缺点是性能较差，因为每次服务调用都需要经过IPC 机制，伴随着频繁的用户态与内核态上下文切换；外核将物理资源的管理权下放给应用程序，应用可以直接访问和管理硬件，彻底避免了微内核中沉重的IPC 和上下文切换开销，因此执行效率通常更高。
