第 1 题
按存储介质分类，下列存储器中属于半导体存储器的是（ ）。
  1. A．机械硬盘
  2. B．光盘
  3. C．SRAM
  4. D．磁带
答案与解析

答案：C

SRAM（静态随机存取存储器）是利用半导体器件的双稳态电路来存储信息，属于半导体存储器，C正确；机械硬盘是磁表面存储器，一般又称磁盘，A错误；光盘是光存储器，B错误；磁带也是磁表面存储器，D错误。注意：固态硬盘属于半导体存储器，其核心存储介质为闪存，不同于机械硬盘。

第 2 题
关于各类存储器的介质特性、存取方式及功能的描述，下列说法正确的是（ ）。
  1. A． SSD 属于磁表面存储器，由于其容量极大且单位成本低，常被用作辅助存储器
  2. B． RAM 和ROM 都采用随机存取方式，因此所有的半导体存储器都按地址随机访问
  3. C． CD-ROM 属于光存储器，存取方式兼有随机访问和顺序访问的特点，属于直接存取（DAM）
  4. D． SRAM 成本太高只能做Cache，ROM 只能固化不能作主存。所以主存全部由DRAM 构成
答案与解析

答案：C

A 选项错误：固态硬盘（SSD）是基于闪存技术（Flash Memory），属于半导体介质。传统的机械硬盘（HDD）才是磁表面存储器。 B 选项错误：RAM 和ROM 确实都采用随机存取方式，但并非所有半导体存储器都是按地址随机访问。例如快表（TLB）和全相联Cache 的Tag 是按内容访问（CAM）的半导体存储器。 C 选项正确：CD-ROM 属于光存储器，光头可以先定位区域（直接）再顺序查找（顺序），这种结合的模式属于直接存取（DAM）。 D选项错误：通用计算机的主存由RAM和ROM共同组成，包含存放系统启动程序的ROM区 （BIOS），所以“全部由DRAM 构成”是错误的。

  2. B．顺序存取存储器
  3. C．直接存取存储器

第 4 题
关于存储器的分类与介质特性，下列说法正确的是（ ）。
  1. A． 固态硬盘（SSD）与机械硬盘（HDD）虽然读写机制不同，但均属于磁表面存储器
  2. B． 计算机的主存绝大部分由DRAM 构成，相比于SRAM，DRAM 的集成度更高且不需要定期刷新
  3. C． 闪存（Flash Memory）属于半导体存储器，本质上是一种电可擦除的只读存储器（EEPROM）
  4. D． CPU 内通用寄存器组属于半导体存储器，主要用来存放运算的中间结果，且为了防止计算机突然断电导致数据丢失，它通常被设计为非易失性存储器
答案与解析

答案：C

A选项错误：传统的机械硬盘（HDD）依靠磁盘盘片和读写磁头工作，属于磁表面存储器；而固态硬盘（SSD）是基于闪存技术（Flash Memory），属于半导体存储器。两者介质完全不同。 B选项错误：这道题的陷阱在于后半句：DRAM是以电容充电原理寄存信息的，电荷会逐渐泄漏，因此必须定期进行刷新；相反，SRAM是以触发器原理寄存信息的，不需要定期刷新。 C选项正确：我们常用的固态硬盘或U盘所使用的闪存（FlashMemory），属于半导体存储器。它在技术分类上属于电可擦除的ROM，即EEPROM ()。 D选项错误：前半句是正确的，CPU内部的通用寄存器组（以及Cache、主存等）都属于半导体存储器，用来存放地址、数据及运算的中间结果。但后半句错误：寄存器属于易失性存储器，一旦断电，内部存储的高低电平状态就会消失，无法永久保存数据。

第 7 题
某计算机系统的内存模块数据总线宽度为128 位，内存模块的存取时间为30ns，连续完成两次独立读写操作之间的恢复时间为20ns。若不考虑其他总线开销，该内存的最大理论带宽以及CPU 每秒钟最多能向其发起的连续访问次数分别是（）。
  1. A． 320MB/s 和2 × 107次
  2. B． 533MB/s 和3.33 × 107次
  3. C． 2.56GB/s 和2 × 107次
  4. D． 4.26GB/s 和3.33 × 107次
答案与解析

答案：A

S 区分存取周期（TC）与存取时间（TA）。CPU 连续访问的最小时间间隔是存取周期，而存储器带宽的计算也必须使用存取周期。存取周期计算：TC= TA + TR= 30ns + 20ns = 50ns。每秒最大连续访问次数：1/(50 × 10−9s) = 2 × 107次。带宽计算：数据位宽W = 128 位= 16 字节(Byte)。 W16Byte理论带宽Bm=TC= 50×10−9s= 3.2 × 108B/s = 320MB/s

第 11 题
关于Cache-主存层次与主存-辅存（外存）层次的异同，下列叙述中错误的是（ ）。
  1. A． 引入Cache-主存层次的主要目的是为了加快CPU 访问信息的速度，而主存-辅存层次则是为了解决主存容量不足的问题
  2. B． CPU 可以直接访问Cache 和主存中的数据，但不能直接访问辅存，辅存的数据必须先调入主存才能被CPU 处理
  3. C． Cache-主存层次的地址映射关系完全由硬件实现并使用标志（Tag）描述，主存-辅存层次的映射关系则由操作系统通过页表来实现
  4. D．Cache-主存层次和主存-辅存层次的数据调度与交换过程，对所有的程序员都是完全透明的
答案与解析

答案：D

D错误：两个层次在“透明性”上是不同的。Cache-主存层次的数据交换完全由硬件自动完成，对所有程序员（无论是应用程序员还是系统程序员）都是透明的；而主存-辅存层次（虚拟存储器）的数据交换由硬件和操作系统共同完成，它只对应用程序员透明，但对系统程序员是不透明的（因为系统程序员需要编写操作系统中的缺页中断处理、页面替换等底层硬件调度代码）。 A正确：准确描述了两者的引入目的。Cache用于提速（填补CPU和主存间的速度鸿沟），虚拟存储器（主存-辅存）用于扩容。 B正确：准确描述了CPU的访问权限。Cache和主存属于内部存储器，CPU可直接寻址访问；辅存属于外部存储器，必须经过主存作为中转。 C正确：准确描述了映射关系的实现介质。Cache为了极致的速度，映射和查找全靠纯硬件电路 （比对Tag）；而主存-辅存层次的缺页代价大，由软件（操作系统）维护的页表（Page Table）来实现虚拟地址到物理地址的映射。

第 12 题
在Cache–主存–外存层次结构中，当CPU 分别遭遇Cache 缺失和缺页异常时，关于系统的处理过程及开销，下列说法错误的是（）。
  1. A． Cache 缺失通常直接由硬件逻辑完成数据的提取和块替换，开销较小
  2. B． 缺页异常会触发处理器的内部异常，需要操作系统介入执行缺页处理程序，开销较大
  3. C． 无论是Cache 缺失还是缺页异常，CPU 都必须暂停当前正在执行的进程，进行线程切换
  4. D． Cache 缺失的开销远小于缺页异常，因为前者访问的是主存，后者需要进行磁盘I/O 操作
答案与解析

答案：C

发生Cache缺失时，CPU通常只是通过流水线停顿（Stall）等待硬件从主存取回数据，不会发生进程/线程的上下文切换；而发生缺页异常时，由于磁盘I/O极慢，操作系统为了提高CPU利用率，会将当前进程阻塞并切换到其他就绪进程。这就把存储器和操作系统的知识完美联动了起来。

第 15 题
下图是DRAM 芯片的内部组件结构示意图，下列说法中正确的是（ ）。
I. 为了节省芯片引脚数量，DRAM 采用了地址复用技术，即同一组地址引脚分两次先后将行地址和列地址送入内部的行、列地址缓冲器
II. 当执行刷新周期时，多路复用器（MUX）会切换到“行地址缓冲器”通道，接收并处理CPU 传来的外部地址以依次进行逐行刷新
III. 读出放大器（在物理上作为行缓冲）不仅负责检测放大电容的微弱信号、自动反向给电容充电以恢复数据，其在保持打开状态时还能起到等效于SRAM 的数据锁存功能
IV. DRAM 刷新操作本质上是一次去掉了“数据输出”步骤的读操作，它依赖内部的刷新计数器提供地址，且该过程中不会打开列译码器
  1. A． I、II、III
  2. B． I、III、IV
  3. C． II、III、IV
  4. D． I、II、IV
答案与解析

答案：B

I正确：为了节省芯片引脚，DRAM采用了“地址复用”技术，即通过同一组引脚（如A0∼A10），先分发行地址（由行地址缓冲器接收），再分发列地址（由列地址缓冲器接收）。 II错误：在执行刷新周期时，多路复用器（MUX）会切换到“刷新计数器”通道，它会无视外部CPU输入的地址，专门把内部刷新计数器自动生成的地址送给行译码器去进行逐行刷新。只有在正常的读写操作时，MUX才会切换到“行地址缓冲器”通道。 III正确：读出放大器可以捕捉位线上的微弱电压变化并迅速极化放大，随后顺着导通的晶体管反向给电容充电，完成破坏性读出后的数据恢复工作；此外，读出放大器在完成信号放大后，利用与SRAM极其相同的电路来锁存数据，在功能上完全等效于一个高速的SRAM缓存（行缓冲）。 IV正确：刷新本质上就是执行了一次没有“数据输出”这一步的读操作（仅执行预充、访问、检测放大、恢复）；刷新时是由刷新计数器指定行地址，不打开列译码器，也不输出数据。综上所述，正确的说法为I、III、IV，故本题选B。

  4. D． 7FFEH

答案：B
