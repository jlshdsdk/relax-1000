第 1 题
下列关于文件的基本概念和属性的叙述中，错误的是（ ）
  1. A．文件的逻辑结构是指从用户角度看到的文件组织形式，如流式文件或记录式文件，它独立于文件的物理存储结构。
  2. B．文件名是用户赋予文件的符号标识，而文件扩展名（如.txt，.exe）通常用于指示文件类型，方便用户和操作系统识别。
  3. C．文件的“只读”属性可以防止用户对文件进行修改，但具有管理员权限的用户仍可能通过调整权限或强制写入的方式修改文件。
  4. D．文件控制块（FCB）或索引节点（inode）是操作系统为管理文件而设置的数据结构，包含了文件名、物理位置、大小、存取权限等元数据。
答案与解析

答案：D

A 正确。文件的逻辑结构是用户可见的文件组织方式，例如文本文件被视为字符流（流式文件），而数据库文件可能由多条记录组成（记录式文件）。这种逻辑组织与文件数据块在磁盘上如何具体存放（物理结构，如连续、链接或索引存放）是分离的。 B 正确，文件名是用户用来识别和访问文件的符号名称。文件扩展名是附加在文件名后的部分，用于帮助用户和操作系统判断文件的类型和可能的用途。 C 正确，文件的“只读”属性确实限制了对文件内容的修改。但是，通常情况下，文件所有者或具有足够权限的系统管理员（超级用户）仍然有权修改文件的属性，包括取消“只读”属性，或者直接对文件进行写操作（尽管可能需要先更改权限）。 D 错误，索引节点（inode）不包含文件名，文件名存储在目录文件的目录项中，每个目录项将文件名与inode 号关联。

第 2 题
文件控制块（FCB）中主要包含（ ）
Ⅰ．文件基本信息
Ⅱ．文件存取控制信息
Ⅲ．文件使用信息
Ⅳ．文件内容
  1. A．仅Ⅰ、Ⅱ
  2. B．仅Ⅰ、Ⅱ、Ⅲ
  3. C．仅Ⅱ、Ⅲ、Ⅳ
  4. D．Ⅰ、Ⅱ、Ⅲ、Ⅳ
答案与解析

答案：B

Ⅰ正确，FCB 中必然包含文件的基本信息，例如文件名（用于用户识别）、文件在外部存储设备上的物理位置（如起始盘块号、占用的盘块数或索引块指针）、文件的逻辑结构（如流式或记录式）、文件的物理结构（如连续、链接、索引）以及文件长度等。 Ⅱ正确，为了实现文件保护，FCB 中会记录文件的存取控制信息，例如文件所有者是谁，以及不同类别的用户（如文件所有者、同组用户、其他用户）对该文件具有的访问权限（如读、写、执行等）。 Ⅲ正确，FCB 中通常还会包含文件的使用历史和状态信息，例如文件的创建日期和时间、最后一次被修改的日期和时间、最后一次被访问的日期和时间，以及当前文件是否被打开、被哪些进程打开、是否有进程锁定了该文件等。 Ⅳ错误，FCB中存放的是文件的描述信息（元数据），例如文件数据存储在磁盘上的哪个位置 （通过物理地址或索引块指针指示），但不包含文件内容本身的数据块。文件内容的数据是存储在磁盘的数据区中的，FCB 的作用是指向这些数据。如果FCB 包含文件内容本身，那么对于大文件，FCB 将会变得异常庞大，不便于管理和快速检索。

第 3 题
下列关于文件控制块的说法中，错误的个数为（ ）
Ⅰ．文件控制块就是文件目录项
Ⅱ．文件控制块是在执行open（打开）系统调用时建立的
Ⅲ．一个文件可以对应有多个文件控制块
Ⅳ．文件控制块通常含有3 类信息：基本信息、存取控制信息及使用信息
  1. A．1
  2. B．2
  3. C．3
  4. D．4
答案与解析

答案：B

文件控制块与文件一一对应(Ⅲ错误)，创建文件时建立对应的文件控制块，而不是打开文件时创建的(Ⅱ错误)。把文件控制块的有序集合称为文件目录，即一个文件控制块就是一个文件目录项(Ⅰ正确)。在文件控制块中，通常含有3 类信息，即基本信息、存取控制信息及使用信息(Ⅳ正确)。所以Ⅳ、Ⅳ正确，Ⅱ、Ⅲ错误。错误的个数为2，所以选B。

第 4 题
下列关于引入索引节点后，文件目录和索引节点的叙述中，正确的是（ ）
  1. A．文件目录是索引节点的有序集合
  2. B．文件目录和索引节点无联系
  3. C．文件目录中分为文件名和索引节点
  4. D．索引节点中有文件的控制信息
答案与解析

答案：D

A 错误，文件目录是由一系列目录项组成的，是文件控制块FCB 的有序集合。在引入索引节点的文件系统中，每个目录项通常包含文件名和指向该文件对应索引节点的指针或编号，而不是索引节点本身。索引节点通常集中存放在磁盘的特定区域（索引节点区）。 B 错误，文件目录和索引节点之间有非常紧密的联系。目录项通过索引节点号（或指针）与索引节点关联起来，实现了文件名到文件具体属性和数据位置的映射。 C 错误，文件目录（或更准确地说是目录文件中的目录项）通常包含文件名和指向索引节点的指针或索引节点号，而不是索引节点本身。索引节点包含了文件的详细元数据。 D 正确，索引节点（inode）是文件系统中用于存储文件元数据的核心数据结构。它包含了关于文件的各种控制信息。

第 5 题
下列关于索引节点的叙述中，错误的是（ ）
  1. A．每个文件都对应一个唯一的索引节点，其中包含了文件的所有者、访问权限、时间戳以及指向文件数据块的指针等信息。
  2. B．引入索引节点后，文件目录项中通常只包含文件名和该文件对应的索引节点号，而不包含文件的其他元数据。
  3. C．当一个文件被多个硬链接指向时，系统会为每个硬链接创建一个独立的索引节点，但这些索引节点会指向相同的物理数据块。
  4. D．索引节点本身存储在磁盘上，当文件被访问时，其对应的索引节点会被加载到内存中以便快速存取。
答案与解析

答案：C

A 正确，索引节点是文件的元数据集合，它详细描述了文件的各种属性，包括文件类型、所有者ID、用户组ID、文件的访问权限（读、写、执行）、各种时间戳（如创建时间、最后修改时间、最后访问时间）、文件大小以及指向存储文件内容的数据块的指针（直接指针、间接指针等）。每个文件在文件系统中都有一个唯一的索引节点。 B 正确，这种设计将文件名与文件的其他描述信息分离。目录项的主要作用是建立文件名到索引节点的映射。通过这种方式，可以减少目录项的大小，提高目录检索效率。 C 错误，硬链接是指多个不同的文件名指向同一个索引节点。这意味着这些文件名共享同一个文件元数据（包括指向数据块的指针）。因此，它们实际上是同一个文件的不同入口。索引节点中通常会有一个链接计数器，记录有多少个目录项指向该索引节点。并不会为每个硬链接创建独立的索引节点。 D 正确，索引节点作为文件系统持久化的一部分，存储在磁盘上。当文件被打开或访问时，操作系统会将该文件的索引节点从磁盘读入内存，以便快速获取文件的元数据和定位数据块，减少后续操作的磁盘I/O 次数。

下列关于inode 的描述，错误的是（ ）
Ⅰ．inode 的数量可随时动态调整。
Ⅱ．每个文件都有一个唯一对应的inode 编号

第 7 题
下列文件信息中并未包含在文件对应的磁盘索引节点中的是（ ）
  1. A．文件的链接计数
  2. B．文件在磁盘中的物理位置
  3. C．文件的读写指针
  4. D．文件的访问权限
答案与解析

答案：C

• 磁盘索引节点：是指存放在磁盘上的索引节点。每个文件有一个唯一的磁盘索引节点，主要包括以下内容：文件主标识符，拥有该文件的个人或小组的标识符。文件类型，包括普通文件、目录文件或特别文件。文件存取权限，各类用户对该文件的存取权限。文件物理地址，每个索引节点中含有13个地址项，即iaddr(0)~iaddr(12)，它们以直接或间接方式给出数据文件所在盘块的编号。文件长度，指以字节为单位的文件长度。文件链接计数，在本文件系统中所有指向该文件的文件名的指针计数。文件存取时间，本文件最近被进程存取、修改的时间及索引节点最近被修改的时间。 • 内存索引节点：是指存放在内存中的索引节点。当文件被打开时，要将磁盘索引节点复制到内存的索引节点中，便于以后使用。在内存索引节点中增加了以下内容：索引节点号，用于标识内存索引节点。状态，指示i 节点是否上锁或被修改。访问计数，每当有一进程要访问此i 节点时，计数加1：访问结束减1。逻辑设备号，文件所属文件系统的逻辑设备号。链接指针，设置分别指向空闲链表和散列队列的指针。综上所述，文件的磁盘索引节点中存放文件的固有信息，包括A 链接计数，B 物理位置和D 访问权限，而文件的读写指针是单个进程对文件的访问相关的，位于用户级打开文件表中。

第 8 题
已知某文件系统采用索引分配的方式，文件索引节点中有8 个直接索引、2 个1 级间接索引和1个2 级间接索引，已知磁盘块的大小是1KB，一个索引指针的大小为4B，若某个文件的索引节点已经放入内存，则修改该文件的第518KB 处的数据需要（）次磁盘I/O
  1. A．1 次
  2. B．2 次
  3. C．3 次
  4. D．4 次

答案：C

文件第518KB 位于第518 个磁盘块中，直接索引负责第0-7 块磁盘块管理，2 个1级索引负责第8-519 块磁盘块的管理，所以第518 块磁盘属于1 级间接索引管理，因此需要先将一级索引块放入内存，再把数据块放入内存，需要两次磁盘I/O，在内存中修改后再通过一次I/O 放回磁盘，共3 次磁盘I/O。

第 10 题
设某文件系统中每个盘块占1KB，索引节点编号占4B，文件名也占4B。则对一个具有640 个文件的目录而言，为了找到某个文件的物理地址信息平均需要启动（）次磁盘。
  1. A．3
  2. B．4
  3. C．5
  4. D．6
答案与解析

答案：B

引入索引节点后，每个目录项只需要存放文件名和索引节点编号即可。1 个盘块可以存放1KB/(4B+4B)=128 个目录项，640 个目录项共需占用640/128=5 个盘块，因此找到对应的目录项平均需要启动(1+2+3+4+5)/5=3 次磁盘；得到目录项后，还需要再启动一次磁盘将对应的索引节点读入内存，故平均需要启动4 次磁盘。

第 11 题
某文件系统的一个磁盘块大小为512B，FCB 的大小为64B，其中文件名占12B。此文件系统的第一版中，目录项包含FCB 的全部内容。为加速目录访问，此文件系统的第二版引入了索引节点，索引节点编号长度为4B。现有一个存放在磁盘上，包含有256 个文件的目录，则两版文件系统在此目录中检索一个文件平均各需访问磁盘（）次。
  1. A．32，9
  2. B．32，8
  3. C．16.5，5.5
  4. D．16.5，4.5
答案与解析

答案：C

第一版中，目录大小为256x64B/512B=32 个磁盘块，故检索一个文件平均需要访问(32+1)/2=16.5 次。第二版中，目录大小为256x(12B+4B)/512B=8 个磁盘块，故检索一个文件的索引节点编号平均需要访间(8+1)/2=4.5 次;读出索引节点编号后，还需访问一次磁盘读出索引节点的内容，因此检索一个文件平均需要访问5.5 次。因此选C。

第 13 题
当用户请求操作系统删除一个当前未被任何进程打开的文件时，操作系统会执行一系列操作来完成此任务。下列操作中，哪一项是操作系统在执行文件删除过程中不会执行的是（）
  1. A．释放该文件内容所占用的全部磁盘块。
  2. B．清除该文件在其父目录中的目录项。
  3. C．回收该文件对应的文件控制块（FCB）或索引节点（inode）所占用的空间。
  4. D．格式化该文件曾经占用的磁盘扇区以清除数据。
答案与解析

答案：D

D 选项，标准的文件删除操作通常只是将文件占用的磁盘块标记为可用，并移除目录项和回收FCB/inode。操作系统一般不会立即去物理地擦除或格式化这些磁盘扇区中的数据内容。这样做开销很大，会显著降低删除操作的效率。数据的物理清除通常需要专门的安全删除工具或在后续磁盘块被重新分配给新文件并写入新数据时才会被覆盖。

第 16 题
各进程读取打开文件的起始位置被记录在（ ）
  1. A．外存索引节点中
  2. B．系统级打开文件表中

第 18 题
若一个用户进程通过read 系统调用读取一个磁盘文件中的数据，则下列关于此过程的叙述中，正确的有（）个；
Ⅰ．read（ ）系统调用需要的参数有文件名，读写指针和期待读取的字节数；
Ⅱ．若该文件的数据不在内存，进程在执行read（）系统调用后，会主动阻塞自己，等待I/O 完成后，在对应的中断服务程序中被唤醒；
Ⅲ．read（ ）系统调用的主要工作就是将文件从磁盘直接读入用户空间中的指定缓冲区；
Ⅳ．read（ ）系统调用只会从磁盘读入指定区域的数据，不会读入无关数据；
Ⅴ．若根据读写指针找到文件的读位置后发现从读位置到文件结束的位置所在区域的字节数小于期待读取的字节数，则读取失败，返回-1；
  1. A．1
  2. B．2
  3. C．3
  4. D．4
答案与解析

答案：A

Ⅰ.错误；read 系统调用需要的参数是read(int fd, void *buf, size_t count)，必须打开文件获得fd 后才能对文件执行读写和关闭操作，因此不需要文件名，需要的是文件描述符；读写指针位于进程打开文件表中，除了文件描述符fd 和期待读取的字节数以外，还需要指定读入用户空间缓冲区的指针；
Ⅱ.正确；假设进程P1执行read()系统调用，由于该文件的数据不在内存，因此需要通过磁盘I/O，在对DMA 控制器设置完传送参数后，便会主动阻塞自己，随后调度程序根据调度策略选择进程P2上处理机，进程P2 执行的过程中，DMA正在将指定读写区域数据所在磁盘块依次读入内核缓冲区，I/O 完成后，DMA 控制器便会发出中断请求，进程P2 响应该中断请求之后，在该中断服务程序中唤醒进程P1，如果进程P1 优先级比当前进程优先级高且为抢占式调度，那么在中断返回过程中，便会触发调度让进程P1 上处理机执行；
Ⅲ.“直接”有误，需要先将指定读写区域所在磁盘块读入内核空间，然后再根据读写指针和读写字节数将所需数据从内核缓冲区复制到用户空间的缓冲区buf 中；
Ⅳ.错误，看C 的解释；
Ⅴ.错误，读取成功，返回实际读取的字节数因为磁盘、硬盘、U 盘等存储设备基本都是Flash 块设备，块设备硬件本身有读写限制等特征，块设备是以一块一块为单位进行读写的（一个块包含多个扇区，而一个扇区包含多个字节），一个字节的改动也需要将该字节所在的block 全部读取出来进行修改，修改完成之后再写入块设备中，所以导致对块设备的读写操作非常不灵活；而内存可以按字节为单位来操作，而且可以随机操作任意地址数据，非常地很灵活，所以对于操作系统来说，会先将磁盘中的静态文件读取到内存中进行缓存，读写操作都是针对这份动态文件，而不是直接去操作磁盘中的静态文件，不但操作不灵活，效率也会下降很多，因为内存的读写速率远比磁盘读写快得多。

  2. B．逻辑结构指文件的组织方式，物理结构指文件在磁盘上的存储方式
  3. C．逻辑结构指文件的组织方式与存储方式，物理结构指文件的存储方式

第 30 题
