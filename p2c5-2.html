第 31 题

  1. A．单周期数据通路中PC 寄存器写使能信号一直有效
  2. B．取指令操作的延时主要由存储器的取数时间决定
  3. C．取指令操作不能和下条指令地址的计算操作同时进行
  4. D．单周期数据通路中数据和指令都存放在同一存储器中
答案与解析

答案：B

A 错，因为是单周期处理器，每个时钟周期执行一条指令，所以每来一个时钟， PC的值都会被更新一次，因而，PC无须“写使能”信号控制。单周期处理器取值部件：假定指令专门存放在指令存储器中，它只有读操作，读指令操作可看成是组合逻辑操作，因此无须控制信号的控制，只要给出指令地址，经过一定的“取数时间”后，指令被送出。指令的地址来自PC，有专门的下地址逻辑来计算下条指令的地址，然后送PC。因为是单周期处理器，每个时钟周期执行一条指令，所以每来一个时钟，PC的值都会被更新一次，因而，PC无须 “写使能”信号控制。下地址逻辑中，要区分是顺序执行还是转移执行。若是顺序执行，则执行PC+4；若是转移执行，则要根据当前指令是分支指令还是跳转指令来计算转移目标地址。 B 正确，因为CPU 需要从存储器中读取指令。 C 错误，因为该时钟周期结束后，要执行下一条指令，在执行下一条指令之前，必须在本条指令中得到下一条指令的地址，也可参考上图的取指部件D 错误，因为单周期指令需要在一个时钟周期内完成指令的所有操作，例如LOAD 指令需要从指令存储器中取指和根据主存地址从数据存储器中取数，因此不能存放在同一个存储器中。

第 32 题
操作控制器一般可分为硬布线控制器和微程序控制器，下列说法中，错误的是（ ）
  1. A．硬布线控制器采用组合逻辑技术实现
  2. B．微程序控制器设计比硬布线控制器设计更具规整性
  3. C．硬布线控制器适合于简单或规整的指令系统
  4. D．微命令和微操作的概念属于微程序控制器专属
答案与解析

答案：D

A 正确，硬布线控制器核心是组合逻辑电路； B 正确，微程序控制器是用微指令序列（存储在控制存储器中）来组织控制逻辑，其结构更规整、易于修改维护。设计层次化、逻辑清晰，便于扩展指令集。注意这里的规则是指硬件设计上的规整，注意区分C 选项中的指令系统规整。 C 正确，MIPS 作为RISC 架构，指令长度固定、格式统一（如所有指令32 位）。硬布线控制器的优点是速度快，适合于实现简单或规整的指令系统。但是，它是一个多输入/多输出的巨大的逻辑网络。对于复杂的指令系统来说，其结构庞杂，实现困难，修改、维护不易，灵活性差。 D 错误，微命令：控制功能部件完成基本操作的信号（如ALUOp=加法）。 • •微操作：由微命令触发的原子操作（如“寄存器A 内容送总线”）。 • 两者是通用概念，并非微程序控制器专属：硬布线控制器：微命令由组合逻辑电路直接生成（如通过指令译码器输出RegWrite信号）。微程序控制器：微命令从微指令字段译码得到。 • 关键区别：微程序控制器中，微命令以微指令形式存储在ROM 中；硬布线控制器中，微命令由硬件逻辑实时生成。

第 35 题
下列有关指令和微指令之间关系的描述中，正确的是（ ）
  1. A．一条指令的功能通过执行一条微指令来实现

第 39 题
水平型微指令与垂直型微指令相比（ ）
  1. A．前者一次只能完成一个操作
  2. B．后者一次只能完成一个操作
  3. C．两者都是一次只能完成一个操作
  4. D．两者都能一次完成多个操作
答案与解析

答案：B

水平型微指令并行操作能力强.效率高，灵活性强，垂直型微指令则较差。在一条水平型微指令中，设置有控制信息传送通路(门)以及进行所有操作的微命令，因此在进行微程序设计时，可以同时定义比较多的并行操作的微命令，来控制尽可能多的并行信息传送，从而使水平型微指令具有效率高及灵活性强的优点；在一条垂直型微指令中，一般只能完成一个操作，控制一两个信息传送通路，因此微指令的并行操作能力低，效率低。

第 45 题
下列关于微程序控制器的地址转移控制，说法错误的是（ ）
  1. A．取指微程序的入口地址是由机器指令的操作码决定的
  2. B．取指微程序的最后一条通常是转移微指令
  3. C．断定法方式下，每条机器指令对应的微程序最后一条微指令的下址字段是取指微程序的首地址
  4. D．计数器方式下，转移控制逻辑必须实现uPC + “1”的功能

第 46 题
以下关于异常和中断的基本概念，说法错误的是（ ）。

外部中断只有在CPU中断允许标志置位时才会被响应，C正确；中断控制器按优先级而非到达顺序排队，A错误；中断时通用寄存器的保存是由中断服务程序（软件）完成，硬件只隐式保存程序计数器等少量状态，B错误；CPU只能在指令的中断允许周期等特定时刻响应中断，而不是在任意时刻立即中断当前指令，D错误。

第 55 题
以下有关CPU 响应外部中断请求的叙述中，正确的是（ ）
  1. A．每条指令结束后，CPU 都会转到“中断响应”周期进行中断响应处理
  2. B．中断I/O 方式下，外设接口中的数据和CPU 中的寄存器内容直接交换
  3. C．CPU 检测异常与中断的时机相同，并且检测到异常事件后所做的处理和检测到中断请求后所做的处理完全一样
  4. D．在中断处理程序结束后的执行iret 指令过程中，会从内核栈中弹出异常/中断响应时保存的用户栈指针
答案与解析

答案：B

A 错误，CPU 在每条指令执行结束时检测中断请求信号，若检测到中断请求信号有效，则进入中断响应周期；若检测到中断请求信号无效，则不会进入中断响应周期B 正确，真题考过，外设接口中的数据即I/O 端口的数据。 C 错误，检测时机不同，所做的处理也不同。由于异常的发生与指令的执行同步，与当前指令的执行过程密切相关，因此在指令执行过程中检测到异常立即响应。而中断是由外部设备或者内部定时器发出的，通常是异步发生的，因此在指令执行完成后检测。CPU 对于异常和中断的响应处理在大的方面基本一致，都需要保存断点和程序状态并转到相应的处理程序去执行。但有些细节并不一-样，例如，在检测到中断请求后CPU 必须通过中断回答信号启动中断控制器进行中断查询，以确定当前发出的优先级最高的中断请求类型，并通过数据线获取相应的中断类型号。而对于内部异常，CPU 则无需进行中断回答。 D 错误，在iret执行的过程中，会从内核栈中弹出异常/中断响应时保存的PC 和PSW 信息（即断点信息），并且会检查异常/中断响应前、后系统是否处于同一个特权级，如果检查出响应前、后处于同一个特权级（即异常/中断是在内核程序执行时发生的，若是中断即表示发生了多重中断），则不需要从内核栈中弹出用户栈指针，因为在这种情况下，异常/中断响应时并没有在内核栈中保存用户栈顶指针。如果检查出前、后不是同一个特权级，则需要弹出用户栈指针。

第 56 题
为消除单周期数据通路的关键路径，可以通过流水线技术来提高CPU 性能。以下结论正确的是（）。
  1. A．流水线级数越多，CPU 主频必然也越高。
  2. B．流水线各阶段组合逻辑延迟最大者决定CPU 的最高频率。
  3. C．流水线不仅能提高系统吞吐率，还能减少单条指令的总执行时间。
  4. D．流水线技术无法使得程序指令并行执行。
答案与解析

答案：B

A 选项错误。虽然增加流水线级数可能缩短每级延迟，但“必然”提高主频的说法过于绝对。实际中，流水线级数增加会引入额外的寄存器延迟（如建立时间、保持时间），且若各阶段延迟不均衡，最慢阶段仍会限制主频。此外，过深的流水线可能导致控制复杂度上升，反而影响性能。因此，当段数到达一定数量时，流水线级数增加不一定会提高主频了。 B 选项正确。流水线的时钟周期必须覆盖最慢阶段的延迟（包括组合逻辑延迟和流水线寄存器延迟），否则会导致数据无法正确传递。因此，CPU 的最高频率由流水线中最关键路径（即延迟最大的阶段）决定。 C 选项错误。流水线技术的核心优势在于提高吞吐率（单位时间内完成的指令数），而非减少单条指令的执行时间。由于流水线寄存器延迟的存在，单条指令的总执行时间可能反而略有增加（如从单周期变为多周期）。虽然主频提高可能缩短时钟周期，但单条指令仍需经历多个阶段，其总执行时间并未减少。 D 选项错误。流水线技术的核心思想正是通过指令级并行（ILP）实现多条指令的不同阶段同时执行。例如，在五级流水线中，每个时钟周期可以处理五条不同指令的不同阶段，从而显著提升并行性。

第 57 题
以下关于指令流水线的说法中，正确的是（ ）。
  1. A．流水线技术主要提高的是单条指令的执行速度
  2. B．稳定的流水线的CPI 一定等于单周期处理器的CPI
  3. C．对流水线调度而言，指令之间完全无关时速度提升最大
  4. D．流水线没有任何开销
答案与解析

答案：C

指令相关性（如数据相关、控制相关）会导致流水线停顿（stall），降低效率。当指令间完全无关时，流水线各阶段可连续执行，无停顿，此时流水线效率最高，C正确；流水线技术通过将指令执行过程分解为多个阶段（如取指、译码、执行等），使不同指令的各阶段并行处理，从而提高整体指令吞吐量，而非单条指令的执行速度，A错误；单周期处理器的CPI等于，稳定的流水线处理器的理想CPI为1，但实际中因数据冒险、控制冒险等需要阻塞，导致CPI有时会大于1，B错误；流水线存在多种开销，如硬件开销，阻塞导致的时间开销等，D错误。

某计算机中，各种指令的CPI 平均为8，CPU 采用5 级流水方式执行指令，流水线每拍为2 个时钟周期。执行程序A 时，共执行了2000 条指令，此时流水线的加速比约为（ ）。

  3. C．8.0

第 59 题
某指令流水线有5 个阶段：取指（IF）、译码（ID）、执行（EX）、访存（MEM）和写回 （WB），每个阶段的执行时间分别为2ns、3ns、4ns、5ns、2ns，则该流水线每个流水段的周期至少为 （）。

  2. B．指令译码得到的控制信号需通过流水段寄存器传递到下一个流水段
