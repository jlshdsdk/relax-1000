第 1 题
在操作系统中，并发（Concurrency）和并行（Parallelism）是两个既相关又有所区别的重要概念。下列关于这两个概念的叙述中，正确的有（）
Ⅰ．并发是指多个任务在宏观上看起来是同时在执行，但在微观上是交替执行的。
Ⅱ．并行是指多个任务在同一物理时刻被同时执行。
Ⅲ．如果一个系统支持并行执行，那么它一定也支持并发执行。
Ⅳ．如果一个系统支持并发执行，那么它一定也支持并行执行。
  1. A．仅Ⅰ、Ⅱ
  2. B．Ⅰ、Ⅱ、Ⅲ
  3. C．Ⅰ、Ⅱ、Ⅳ
  4. D．Ⅰ、Ⅱ、Ⅲ、Ⅳ
答案与解析

答案：B

Ⅰ正确，并发是指两个或多个事件在同一时间间隔内发生。在多道程序环境下，在内存中同时装有若干道程序，以便当运行某道程序时，利用其因I/O操作而暂停执行时的CPU空档时间，再调度另道程序运行，从而实现多道程序交替运行，使CPU 保持忙碌状态。 Ⅱ正确，并行性是指系统具有同时进行运算或操作的特性，在同一时刻能完成两种或两种以上的工作。 Ⅲ正确，一个能够并行执行多个任务的系统（即有多处理单元）自然也能够通过在这些处理单元上交替执行更多的任务来实现并发。并行是并发的一种特殊形式，或者说，并行系统可以更容易地实现并发。 Ⅳ错误，单处理器系统通过多道程序技术和快速的任务切换可以实现并发，使得多个任务在一段时间内交替使用CPU。但是，由于在任何一个时刻只有一个任务真正在CPU 上执行，因此无法实现真正的并行（多个任务在同一时刻执行）。

第 3 题
下列关于批处理系统的叙述中，正确的是（ ）
Ⅰ．批处理系统中，用户与自己所提交的作业无交互能力
Ⅱ．单道批处理系统中，需要把作业以脱机I/O 方式输入到磁带，无需设置监督程序
Ⅲ．多道批处理系统需要运行在多CPU 的硬件平台上
Ⅳ．多道批理系统需要运行在实现中断机制的硬件平台上
  1. A．Ⅰ、Ⅱ、Ⅲ
  2. B．Ⅰ、Ⅱ、Ⅳ
  3. C．Ⅰ、Ⅳ
  4. D．Ⅱ、Ⅲ
答案与解析

答案：C

批处理系统中，用户一旦把作业提交给系统，那么直至作业完成，用户都不能与自己的作业进行交互，为此才诞生了分时系统，故Ⅰ正确。单道批处理系统中，为了实现对作业的连续处理，需要先把一批作业以脱机IO方式输入到磁带上，并在系统中配上监督程序。在它的控制下，这批作业能一个接一个地被连续处理。故Ⅱ错误。多道批处理系统中，用户所提交的作业都先存放在外存上并排成一个队列，作业调度程序按一定的算法从后备队列中选择若干作业调入内存，它们在管理程序的控制下相互穿插地运行，共享系统中的各种硬软件资源。当某道程序因请求I/O操作而暂停运行时，CPU便立即转去运行另一道程序，这是通过中断机制实现的，无需多CPU 的支持，故Ⅲ错误，Ⅳ正确。综上，选C。

第 4 题
与多道批处理系统相比，单道批处理系统（ ）
Ⅰ．CPU 利用率低
Ⅱ．系统开销小
Ⅲ．系统吞吐量大
Ⅳ．I/O 设备利用率高
  1. A．Ⅰ、Ⅱ
  2. B．Ⅰ、Ⅳ
  3. C．Ⅱ、Ⅲ
  4. D．Ⅱ、Ⅲ、Ⅳ
答案与解析

答案：A

多道批处理系统通过组织作业(编码或数据)使CPU总有一个作业可执行，从而提高了CPU 的利用率、系统吞吐量和IO设备利用率，但系统要付出额外的开销来组织作业和切换作业。单道批处理系统与之相比，CPU 利用率更低，系统开销更小，系统吞吐量更小，I/O 设备利用率更低，故选Ⅰ、Ⅱ。注意：有同学可能会认为Ⅰ与Ⅳ正好对应，CPU 利用率低，那I/O 利用率就高，从而错选B。单道批处理系统，CPU 和I/O 同一时刻只能运行一个，而多道批处理系统可以通过中断技术实现CPU 与I/O并行，两者的利用率均更高。

第 5 题
下列关于多道程序系统的叙述中，不正确的是（ ）
  1. A．必须要解决内存保护与分配问题。
  2. B．必须支持虚拟存储管理
  3. C．必须要实现对共享资源的管理
  4. D．必须要解决处理机争用问题
答案与解析

答案：B

多道程序系统（多道批处理系统），为使系统中的多道程序间能协调地运行，系统必须解决下述一系列问题。
①争用处理机问题：系统既要能满足各道程序运行的需要，又要能提高处理机的利用率。
②内存分配与保护问题：系统应能为每道程序分配必要的内存空间，以使它们“各得其所”，且不会因某道程序出现异常情况而破坏其他程序。
③I/O 设备分配问题：系统应采取适当的策略来分配系统中的IO 设备，以达到既能方便用户对设备的使用，又能提高设备利用率的目的。
④文件的组织与管理问题：系统应能有效地组织存放在系统中的大量程序和数据，以使它们既便于用户使用，又能保证数据的安全性。
⑤作业管理问题：系统中存在着各种作业(应用程序)，系统应能对系统中所有的作业进行合理的组织，以满足这些作业对应用户的不同要求。
⑥用户与系统的接口问题：为使用户能方便地使用OS，OS 还应提供用户与OS 之间的接口。故A，C，D 正确。早期的多道批处理操作系统会将所有进程的数据全部调入主存，再让多道程序并发执行，即使不支持虚拟存储管理，也能实现“多道程序并发”，B 错误。

第 6 题
下面关于多道程序系统的描述，正确的是（ ）
Ⅰ．可以提高CPU 的利用率和I/O 设备的利用率
Ⅱ．必须存在用户与计算机之间的交互性支持
Ⅲ．不一定需要地址重定位相关的硬件支持
Ⅳ．必须存在地址保护机制
  1. A．仅Ⅰ、Ⅲ
  2. B．仅Ⅲ、Ⅳ
  3. C．Ⅰ、Ⅲ、Ⅳ
  4. D．Ⅰ、Ⅱ、Ⅲ、Ⅳ
答案与解析

答案：C

Ⅰ正确，当采用多道程序设计时，一个进程在进行I/O 的时候，另一个进程可以同步使用CPU，而单道程序设计下系统内存中同时仅存在一个进程，当进程占用CPU时其他进程无法使用CPU，同样当进程在I/O时其它进程也无法使用CPU，因此多道程序可以同时提高CPU和I/O设备的利用率。 Ⅱ错误，批处理程序分为单道批处理和多道批处理。多道批处理系统中用户所提交的作业都先存放在外存上并排成一个队列，作业调度程序按一定的算法从后备队列中选择若干作业调入内存，它们在管理程序的控制下相互穿插地运行。多道批处理不提供人机交互能力。 Ⅲ正确，Ⅳ正确。静态重定位（地址转换在进程装入时一次完成，无需地址重定位寄存器）和动态重定位（内存中的程序可能移动，需要重定位寄存器的支持）均可以适用于多道程序系统。而这两种方式下都需要进行内存保护，以防止多个进程运行时访问的内存空间不会发生冲突。综上所述，选C。

第 7 题
下列关于批处理技术和多道程序设计技术说法中，正确的是（ ）
Ⅰ．批处理系统的最主要缺点是不能并发执行
Ⅱ．所谓多道程序设计，是指每一个时刻有若干个进程在执行
Ⅲ．引入多道程序设计的前提条件之一是系统具有中断功能
Ⅳ．在采用多道程序设计的系统中，系统的程序道数越多，系统的效率越高
  1. A．仅Ⅲ
  2. B．仅Ⅰ、Ⅱ
  3. C．仅Ⅰ、Ⅳ
  4. D．仅Ⅱ、Ⅲ
答案与解析

答案：A

Ⅰ错误，批处理系统的最主要缺点是缺乏交互性。Ⅰ的表述肯定是错的，多道批处理系统是可以并发执行多个程序的。这里的多道是指允许多个进程同时驻留在主存中，按照某种原则分派处理机，逐个执行这些程序。这里其实还考查了并发性的概念：并行性是指两个或多个事件在同一时刻发生；而并发性是指两个或多个事件在同一时间间隔内发生。 Ⅱ错误，多道程序设计是指把多个程序同时存放在内存中，使它们同时处于运行状态。但是，在单处理机环境中，同一时刻只能有一个进程在执行。 Ⅲ正确，有了中断后才能实现进程间并发，进程间并发才有可能把多个进程装入到内存实现多道程序技术。 Ⅳ错误，程序道数如果过多的话，会导致每个程序分配到的内存不够，很多程序所需的程序和代码需要时从磁盘调入到内存，系统会频繁地处于I/O 状态中，导致系统效率降低。

第 8 题
响应时间是衡量分时操作系统性能的重要指标，下列选项中，能够改善响应时间的是（ ）
  1. A．允许用户修改系统时间
  2. B．加大时间片
  3. C．允许中断嵌套
  4. D．采用抢占式优先级调度
答案与解析

答案：D

A.允许用户修改系统时间：这仅改变系统时钟的设置，与进程调度和响应时间无关，不会改善响应时间。 B.加大时间片：时间片是分时系统中每个进程被分配的时间量子。加大时间片会导致每个进程运行时间延长，从而增加其他进程的等待时间，使响应时间变差。 C.允许中断嵌套：中断嵌套允许高优先级中断在处理低优先级中断时被响应，这可以减少中断延迟，从而间接改善系统对I/O 事件的响应。但中断嵌套主要影响中断处理效率，对进程级的响应时间改善不如调度策略直接。 D.采用抢占式优先级调度：这种调度方式允许高优先级进程抢占当前运行的低优先级进程，从而确保高优先级进程（如交互式用户进程）能够及时获得CPU 时间，直接减少响应时间。在分时系统中，这是改善响应时间的有效方法。所以正确答案为D 选项。

第 9 题
下列技术中，分时操作系统必须实现的有（ ）
Ⅰ．时钟中断
Ⅱ．共享资源保护
Ⅲ．多道程序设计
Ⅳ．虚拟内存管理
  1. A．Ⅰ、Ⅱ、Ⅲ
  2. B．Ⅰ、Ⅱ、Ⅳ
  3. C．Ⅰ、Ⅲ、Ⅳ
  4. D．Ⅰ、Ⅱ、Ⅲ、Ⅳ
答案与解析

答案：A

Ⅰ必须实现。分时操作系统的核心是让多个用户通过终端与计算机交互，每个用户感觉自己独占计算机。为了实现这一点，系统采用时间片轮转的方式，让每个进程执行一小段时间后就切换到下一个进程。这种时间片的控制和进程的切换依赖于时钟中断。当一个进程的时间片用完时，时钟硬件会产生中断，操作系统内核响应中断，剥夺当前进程的CPU 使用权，并进行进程调度。 Ⅱ必须实现。分时系统允许多个用户（进程）并发执行并共享系统资源（如内存、I/O 设备、文件等）。为了防止并发访问共享资源时产生冲突和数据不一致，操作系统必须提供共享资源保护机制，如互斥锁、信号量等，确保资源的安全和有序访问。 Ⅲ必须实现。分时系统的基础是多道程序设计。多道程序设计允许内存中同时驻留多个用户作业 （进程），这些进程可以并发执行，从而提高了CPU 和系统资源的利用率。没有多道程序设计，就无法实现多个用户同时使用计算机并进行交互的场景。 Ⅳ非必须实现，但非常普遍。虚拟内存管理技术（如请求分页）允许程序使用的逻辑地址空间远大于实际物理内存，并通过按需调页和页面置换来管理内存。虽然虚拟内存能极大地提高内存利用率和支持运行更大的程序或更多的并发进程，但它并非分时操作系统存在的绝对必要条件。早期的分时系统可能不具备完善的虚拟内存管理，而是依赖于如对换（swapping）等技术。现代分时操作系统几乎都实现了虚拟内存管理，因为它能显著提升系统性能和用户体验。

第 10 题
现有一分时操作系统，其就绪队列中有100 个进程，欲使队尾的进程P 响应时间不超过2s，则该分时操作系统的时间片最大为（）
  1. A．10ms
  2. B．20ms
  3. C．50ms
  4. D．100ms

响应时间是响应所有就绪进程的时间之和，即响应时间=就绪进程数x 时间片。因此当响应时间最大为2s时，时间片最大为2s/100=20ms，所以正确答案为B选项。

第 13 题
下列选项中，只能在内核态执行的是（ ）
  1. A．命令解释程序
  2. B．程序跳转指令
  3. C．自陷指令
  4. D．缺页处理程序
答案与解析

答案：D

CPU 的执行状态分为用户态和内核态。操作系统内核运行在内核态，可以执行特权指令和访问所有硬件资源；用户程序运行在用户态，只能执行非特权指令，访问系统资源需要通过系统调用陷入内核态。 A.命令解释程序：命令解释程序（如Shell）是用户与操作系统交互的接口程序，它本身是一个用户级应用程序，运行在用户态。它接收用户命令，然后通过系统调用请求内核执行相应的功能。 B.程序跳转指令：跳转指令（如JMP）是普通的CPU 指令，用于改变程序执行流程。它既可以在用户态执行（在用户程序内部跳转），也可以在内核态执行（在内核代码内部跳转），属于非特权指令。它本身不特指在哪种状态下执行。 C.自陷指令：自陷指令（如trap）是一种特殊的指令，其目的是为了让用户程序能够主动从用户态切换到内核态，以请求操作系统服务或处理异常。指令本身是在用户态被执行，执行后CPU 会陷入内核态，转去执行对应的内核处理程序。 D.缺页处理程序)：缺页是内存管理中的一种异常（或称为内中断）。当进程访问的页面不在物理内存中时，CPU 会产生缺页异常，并强制从用户态切换到内核态，转去执行操作系统内核中的缺页处理程序，由该程序负责将所需页面调入内存。因此，缺页处理程序运行在内核态。综上所述，缺页处理程序是在内核态执行的，选D。

第 16 题

Ⅰ．执行算术运算指令（如加法、减法）
Ⅱ．发生硬件中断（如时钟中断、I/O 完成中断）
Ⅲ．程序执行过程中发生除零错误
Ⅳ．程序主动调用操作系统的服务（如文件读写）
  1. A．仅Ⅱ、Ⅲ
  2. B．仅Ⅱ、Ⅳ
  3. C．仅Ⅱ、Ⅲ、Ⅳ
  4. D．Ⅰ、Ⅱ、Ⅲ、Ⅳ
答案与解析

答案：C

CPU 从用户态转换到内核态主要是由中断、异常或系统调用引起的。
Ⅰ.执行算术运算指令：普通的算术运算指令（如加法、减法）属于非特权指令，在用户态下正常执行，不会引起CPU 模式的转换。只有当算术运算导致异常（如除零错误）时才会转换。

Ⅳ.程序主动调用操作系统的服务：用户程序需要操作系统提供服务（如文件读写、创建进程等）时，必须通过系统调用接口（如read）来实现。执行系统调用会引发陷入（trap），使CPU 从用户态切换到内核态，由内核执行相应的服务程序。因此，Ⅱ、Ⅲ、Ⅳ都会必然触发CPU 从用户态到内核态的转换。故选C。

  2. B．从内存中读取一个普通变量的值到寄存器

  4. D．执行整数除法指令，且除数为0 ）系统调用以创建子进程

下列选项中，能够引起外部中断的有（ ）
Ⅰ．时间片结束
Ⅱ．键盘输入
Ⅲ．访存缺页
Ⅳ．I/O 操作结束
  1. A．仅Ⅰ、Ⅱ
  2. B．仅Ⅱ、Ⅲ、Ⅳ
  3. C．仅Ⅰ、Ⅱ、Ⅳ
  4. D．Ⅰ、Ⅱ、Ⅲ、Ⅳ
答案与解析

答案：C

中断是指CPU 对系统中或系统外发生的异步事件所做的一种响应。根据中断信号的来源，中断可以分为外部中断（或称硬件中断）和内部中断（或称异常、陷入）。外部中断（Hardware Interrupts）：指来自CPU 处理器以外的中断信号，通常由外部设备（如I/O设备、时钟）或外部事件引起。
Ⅰ.时间片结束：在分时操作系统中，时间片结束是由时钟部件（定时器）产生的时钟中断引起的。定时器是CPU 外部的硬件，因此时钟中断属于外部中断。

Ⅳ. I/O 操作结束：当外部设备（如磁盘、打印机等）完成CPU 下达的I/O 操作后，会向CPU 发出中断信号，通知CPU 操作已完成。这也是一种常见的外部中断。内部中断（Exceptions/Traps）：指来自CPU 处理器内部的中断信号，通常是由于CPU 在执行指令过程中检测到某些错误或特定条件而引起的。
Ⅲ.访存缺页：访存缺页是在执行一条指令的过程中，当该指令要访问的页面不在物理内存时，由CPU 内部的内存管理单元（MMU）检测到并产生的一种异常。这属于内部中断。综上所述，能够引起外部中断的是时间片结束、键盘输入和I/O 操作结束。因此，选项Ⅰ、Ⅱ、Ⅳ正确，选C。

本题需要区分CPU时钟和系统时钟，前者与时钟周期相关，是计算机的固有硬件属性，后者用来负责时钟中断，可以由操作系统来进行设定和初始化。系统时钟可以由操作系统来进行设定和初始化，因此Ⅰ错误；时钟中断由系统时钟发出，属于外中断，Ⅱ错误；计算机中的基本计时单位是由CPU时钟决定的时钟周期，因此Ⅲ错误；发生时钟中断时，操作系统会检查当前进程的时间片，若时间片用完则触发进程调度，因此Ⅳ正确。答案选A。

第 28 题
下列关于操作系统提供的接口管理功能的叙述中，正确的是（ ）
  1. A．联机用户接口用于多用户系统中各用户的交互与通信。
  2. B．脱机用户接口是为批处理作业的用户准备的，用户们通过脱机用户接口与批处理作业进行交互。
  3. C．图形用户接口相比联机用户接口操作更方便，性能更优秀，运行图形界面耗费的资源也更少。
  4. D．程序接口是用户程序获得OS 服务的唯一途径。
答案与解析

答案：D

A 错误，联机用户接口通常也被称为命令行方式(command-lime interface，是C)为联机用户提供的，它由一组键盘操作命令及命令解释程序组成。当用户在终端或控制台上键入一条命令后，系统便会立即转入命令解释程序，对该命令加以解释并执行。在完成指定操作后，“控制”又会返回到终端或控制台上，等待用户键入下一条命令。这样，用户就可以通过先后键入不同命令的方式来实现对作业的控制，直至作业完成。 B 错误，脱机用户接口即批命令方式，是为批处理作业的用户提供的。用户使用作业控制语言(jobcontrollanguage，JCL)把需要对作业进行的控制和干预的命令，事先写在作业说明书上，然后将它与作业连在一起提供给系统，而不是通过脱机用户接口与批处理作业进行交互，批处理的最大问题就是用户无法进行交互。当系统调度到该作业运行时，是通过调用命令解释程序去对作业说明书上的命令逐条进行解释执行的，直至遇到作业结束语句时，系统才会停止该作业的运行。 C 错误，采用非常容易识别的各种图标来将系统的各项功能、各种应用程序和文件直观、逼真地表示出来。用户可以通过菜单(和对话框)，用移动鼠标选择菜单项的方式取代命令的键入，这样可以方便、快捷地完成对应用程序和文件的操作，从而把用户从烦琐且单调的操作中解脱出来。但是运行图形界面会耗费更多的资源，对操作系统的性能有一定的影响。 D 正确，首先要明确：程序接口是由一组系统调用组成的，每个系统调用都是一个能完成特定功能的子程序。每当应用程序要求OS 提供某种服务(功能)时，便调用具有相应功能的系统调用。该接口是为用户程序在执行中访问系统资源而设置的，是用户程序取得OS 服务的唯一途径。

第 29 题
下列关于系统调用的叙述中，正确的是（ ）。
Ⅰ．在调用系统调用时，CPU 处于用户态
Ⅱ．系统调用服务例程在内核态执行，可以访问系统核心资源并执行特权指令
Ⅲ．为了应用程序的跨平台兼容性，所有主流操作系统都应采用完全相同的系统调用接口定义
Ⅳ．系统调用是操作系统内核为应用程序提供服务的接口
  1. A．仅Ⅰ、Ⅱ
  2. B．仅Ⅰ、Ⅱ、Ⅳ
  3. C．仅Ⅱ、Ⅲ、Ⅳ
  4. D．Ⅰ、Ⅱ、Ⅲ、Ⅳ
答案与解析

答案：B

Ⅰ正确，用户程序在CPU 用户态下执行，通过调用系统调用，将CPU 控制权交给操作系统内核。 Ⅱ正确，系统调用服务例程是操作系统内核的一部分，因此它在内核态执行。在内核态下，操作系统拥有最高权限，可以执行所有特权指令（如I/O 操作、修改内存管理寄存器等），并访问系统中的所有核心资源和数据结构，以完成用户程序的请求。 Ⅲ错误，不同的操作系统通常有其自己设计的系统调用接口，包括系统调用的名称、编号、参数以及具体功能实现。虽然有一些标准（如POSIX）试图为类UNIX 系统提供一定程度的接口统一性，但并不能说所有主流操作系统都采用完全相同的系统调用接口。 Ⅳ正确，这是系统调用的一个主要目的。通过将敏感操作（如设备访问、内存管理、文件系统操作）封装在内核态的系统调用中，操作系统可以对用户程序的请求进行检查和控制，确保这些操作不会危害系统的稳定性和安全性。综上所述，选B。

第 30 题
下列选项中，不需要通过系统调用完成的操作是（ ）
  1. A．应用程序创建一个新的进程
  2. B．应用程序打开一个指定路径的文件
  3. C．应用程序访问虚拟内存
  4. D．应用程序从网络套接字接收数据
答案与解析

答案：C

C 选项，访问虚拟内存是进程直接访问内存，由MMU完成虚拟地址向物理地址的转换，这个过程由硬件完成不需要操作系统参与，若发生缺页，则触发缺页异常，由异常处理程序完成页面装入，因此无论哪种情况都不需要用户程序发起系统给调用。A，B，D 均由用户主动发起的请求操作系统提供服务，属于系统调用的范畴。
